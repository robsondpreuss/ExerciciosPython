01

try / except: errar sem quebrar

Conceito

Até hoje, um erro = programa morto. Mas erros têm nome e podem ser capturados:

estrutura.py
try:
    # código que PODE dar erro
    numero = int(input("Número: "))
except ValueError:
    # plano B se o erro acontecer
    print("Isso não é um número!")

Se tudo der certo, o except é ignorado. Se o erro estourar, o Python pula para o plano B em vez de quebrar. Profissionais chamam isso de programação defensiva.

02

Gravando arquivos

Conceito

Tudo que seus programas fizeram até hoje EVAPORA quando eles fecham. Arquivos resolvem isso:

estrutura.py
with open("dados.txt", "w", encoding="utf-8") as arquivo:
    arquivo.write("primeira linha\n")

Os modos: "w" (write) cria o arquivo — e APAGA se já existir! "a" (append) acrescenta no final sem apagar. O with fecha o arquivo sozinho ao terminar (sempre use!). E o \n quebra a linha — o write não quebra sozinho como o print.

solucao_ex11.py
notas = []

with open("notas.txt", "r", encoding="utf-8") as arquivo:
    for linha in arquivo:

EX 12

O "CSV caseiro" 📊

⭐⭐⭐ desafio
🎯 Objetivo

Guardar VÁRIOS dados por linha com separador — o formato dos dados profissionais.

🧭 Passo a passo
  1. Crie produtos.txt com linhas no formato nome;preco — ex.: caneca branca;25.00
  2. Leia cada linha, use split(";") para separar os campos
  3. Desempacote: nome, preco = linha.strip().split(";")
  4. Exiba como tabela e some o total
✅ Saída esperada
terminal
caneca branca — R$ 25.00
caneca preta — R$ 27.50
azulejo — R$ 40.00
TOTAL: R$ 92.50
💡 Você acabou de inventar o CSV!
Arquivos com "valores separados por caractere" são o formato CSV — o mesmo que o Excel exporta. Você está a um passo de processar planilhas com Python! 🤯
🔑 Ver solução

Só abra depois de tentar!

solucao_ex12.py
total = 0

with open("produtos.txt", "r", encoding="utf-8") as arquivo:
    for linha in arquivo:
        nome, preco = linha.strip().split(";")
        preco = float(preco)
        total = total + preco
        print(f"{nome} — R$ {preco:.2f}")

print(f"TOTAL: R$ {total:.2f}")

def salvar_tarefas(tarefas):
    with open("tarefas.txt", "w", encoding="utf-8") as arquivo:
        for tarefa in tarefas:
            arquivo.write(tarefa + "\n")

def carregar_tarefas():
    try:
        tarefas = []
        with open("tarefas.txt", "r", encoding="utf-8") as arquivo:
            for linha in arquivo:
                tarefas.append(linha.strip())
        return tarefas

Projeto: Registro de vendas Tua Caneca 💾

⭐⭐⭐ desafio
🎯 Objetivo

Vendas que sobrevivem: cada venda vira uma linha no arquivo, e o relatório lê tudo.

🧭 Requisitos
  1. Menu: 1-Registrar venda · 2-Relatório · 3-Sair
  2. Registrar: peça cor e quantidade; grave cor;quantidade;total com modo "a" em vendas.txt
  3. Relatório: leia o arquivo (protegido com FileNotFoundError!), some os totais e conte as vendas
  4. Use sua pedir_inteiro() nas entradas numéricas!
✅ Exemplo de execução
terminal
1-Registrar  2-Relatório  3-Sair
Opção: 2
Vendas registradas: 3
Faturamento total: R$ 175.00
🔑 Ver solução

Só abra depois de tentar!

solucao_ex14.py
PRECO = 25.00

def pedir_inteiro(mensagem):
    while True:
        try:
            return int(input(mensagem))
        except ValueError:
            print("Digite um número inteiro!")

while True:
    print()
    print("1-Registrar  2-Relatório  3-Sair")
    opcao = pedir_inteiro("Opção: ")

    if opcao == 1:
        cor = input("Cor: ")
        qtd = pedir_inteiro("Quantidade: ")
        total = qtd * PRECO
        with open("vendas.txt", "a", encoding="utf-8") as arquivo:
            arquivo.write(f"{cor};{qtd};{total}\n")
        print(f"Venda registrada: R$ {total:.2f}")
    elif opcao == 2:
        try:
            vendas = 0
            faturamento = 0
            with open("vendas.txt", "r", encoding="utf-8") as arquivo:
                for linha in arquivo:
                    cor, qtd, total = linha.strip().split(";")
                    vendas = vendas + 1
                    faturamento = faturamento + float(total)
            print(f"Vendas registradas: {vendas}")
            print(f"Faturamento total: R$ {faturamento:.2f}")
        except FileNotFoundError:
            print("Nenhuma venda registrada ainda.")
    elif opcao == 3:
        break
    else:
        print("Opção inválida!")

def salvar_tarefas(tarefas):
    with open("tarefas.txt", "w", encoding="utf-8") as arquivo:

def pedir_inteiro(mensagem):
    while True:
        try:
            return int(input(mensagem))
        except ValueError:
            print("Digite um número!")

while True:
    print()
    print("1-Adicionar  2-Listar  3-Buscar  4-Sair")
    opcao = pedir_inteiro("Opção: ")

    if opcao == 1:
        nome = input("Nome: ")
        telefone = input("Telefone: ")
        with open("contatos.txt", "a", encoding="utf-8") as arquivo:
            arquivo.write(f"{nome};{telefone}\n")
        print("Contato salvo!")
    elif opcao == 2:
        try:
            with open("contatos.txt", "r", encoding="utf-8") as arquivo:
                for linha in arquivo:
                    nome, telefone = linha.strip().split(";")
                    print(f"— {nome}: {telefone}")
        except FileNotFoundError:
            print("Agenda vazia.")
    elif opcao == 3:
        busca = input("Buscar: ")
        encontrado = False
        try:
            with open("contatos.txt", "r", encoding="utf-8") as arquivo:
                for linha in arquivo:
                    nome, telefone = linha.strip().split(";")
                    if nome == busca:
                        print(f"{nome}: {telefone}")
                        encontrado = True
        except FileNotFoundError:
            pass
        if not encontrado:
            print("Não encontrado!")
    elif opcao == 4:
        break
