01

import e o módulo math

Conceito

Um módulo é um arquivo de funções prontas. O Python vem com uma "biblioteca padrão" gigante — e a chave de acesso é o import:

formas.py
import math               # traz o módulo inteiro
print(math.sqrt(25))      # usa com o prefixo math.

from math import sqrt     # traz só o que você quer
print(sqrt(25))           # usa sem prefixo

Você já fez isso na Semana 3 com import random! Agora vamos conhecer o ecossistema de verdade.

sqrt = raiz quadrada (square root) · pi = a constante π · floor = arredonda para BAIXO (chão) · ceil = para CIMA (teto). Repare: sqrt devolve float (5.0), mesmo quando a raiz é exata.

Calculadora de círculo ⭕

⭐⭐ médio
🎯 Objetivo

Usar math.pi num cálculo real, organizado em funções.

🧭 Passo a passo
  1. Crie area(raio) que retorna math.pi * raio ** 2
  2. Crie perimetro(raio) que retorna 2 * math.pi * raio
  3. Peça o raio e exiba os dois resultados com 2 casas decimais

solucao_ex03.py
import math

    return math.pi * raio ** 2

    return 2 * math.pi * raio

print(f"Perímetro: {perimetro(raio):.2f}")

random a fundo

Conceito

Você já conhece o randint do jogo de adivinhação. O módulo random tem muito mais:

FunçãoO que faz
randint(a, b)inteiro entre a e b (os dois inclusos)
random()decimal entre 0 e 1
choice(lista)sorteia UM item da lista
shuffle(lista)embaralha a lista (no lugar)
sample(lista, n)sorteia n itens SEM repetição

from datetime import datetime, date

hoje = date.today()

Sua primeira biblioteca 🧰

⭐⭐⭐ desafio
🎯 Objetivo

Separar funções num módulo e importá-las de outro arquivo.

🧭 Passo a passo
  1. Crie ferramentas.py com eh_par(n) e calcular_media(lista)
  2. NA MESMA PASTA, crie principal.py que importa e usa as duas
  3. Execute o principal.py — as funções vieram do outro arquivo!
✅ Saída do principal.py
terminal
8 é par? True
Média: 7.5
🔑 Ver solução

Só abra depois de tentar!

ferramentas.py
def eh_par(n):
    return n % 2 == 0

def calcular_media(notas):
    return sum(notas) / len(notas)
principal.py
from ferramentas import eh_par, calcular_media

print(f"8 é par? {eh_par(8)}")
print(f"Média: {calcular_media([8, 7, 7.5])}")

É assim que projetos grandes se organizam: cada arquivo cuida de um assunto. Os dois arquivos precisam estar na mesma pasta!

def pedir_inteiro(mensagem):
    while True:
        try:
            return int(input(mensagem))
        except ValueError:
            print("Digite um número inteiro!")

    while True:
        try:
            return float(input(mensagem))
        except ValueError:
            print("Digite um número!")

EX 14

Projeto: Jogo de dados 🎲

⭐⭐⭐ desafio
🎯 Objetivo

Um cassino de dados com saldo, apostas e dois randints.

🧭 Requisitos
  1. Comece com saldo = 100
  2. Em loop: mostre o saldo, peça a aposta (0 sai; maior que o saldo → avise e continue)
  3. Peça o palpite da SOMA de dois dados (2 a 12), role os dados e compare
  4. Acertou: ganha 5× a aposta. Errou: perde a aposta. Saldo zerou? Fim de jogo!
✅ Exemplo de execução
terminal
Saldo: R$ 100
Aposta (0 sai): R$ 20
Palpite da soma (2 a 12): 7
🎲 Saíram 3 e 4 → soma 7
ACERTOU! +R$ 100
🚀 Desafio extra
Use time.sleep(1) entre os dois dados para criar suspense. 😄
🔑 Ver solução

Só abra depois de tentar!

solucao_ex14.py
import random

saldo = 100

while saldo > 0:
    print(f"\nSaldo: R$ {saldo}")
    aposta = int(input("Aposta (0 sai): R$ "))
    if aposta == 0:
        break
    if aposta > saldo:
        print("Saldo insuficiente!")
        continue
    palpite = int(input("Palpite da soma (2 a 12): "))
    d1 = random.randint(1, 6)
    d2 = random.randint(1, 6)
    soma = d1 + d2
    print(f"🎲 Saíram {d1} e {d2} → soma {soma}")
    if palpite == soma:
        ganho = aposta * 5
        saldo = saldo + ganho
        print(f"ACERTOU! +R$ {ganho}")
    else:
        saldo = saldo - aposta
        print(f"Errou! -R$ {aposta}")

print(f"Fim de jogo. Saldo final: R$ {saldo}")

Projeto: Recibo com data e hora ☕🕐

⭐⭐⭐ desafio
🎯 Objetivo

Tua Caneca emite recibos carimbados com datetime — e arquiva tudo.

🧭 Passo a passo
  1. Peça a quantidade e calcule o total (R$ 25,00 cada)
  2. Carimbe: datetime.now().strftime("%d/%m/%Y %H:%M")
  3. Monte a linha do recibo e grave em recibos.txt com modo "a" (Semana 7!)
  4. Exiba o recibo na tela também
✅ Exemplo de execução
terminal
Quantidade: 3
=== RECIBO TUA CANECA ===
12/06/2026 14:45 - 3 caneca(s) - R$ 75.00
🔑 Ver solução

Só abra depois de tentar!

solucao_ex15.py
from datetime import datetime

PRECO = 25.00

qtd = int(input("Quantidade: "))
total = qtd * PRECO
agora = datetime.now().strftime("%d/%m/%Y %H:%M")

recibo = f"{agora} - {qtd} caneca(s) - R$ {total:.2f}"

with open("recibos.txt", "a", encoding="utf-8") as arquivo:
    arquivo.write(recibo + "\n")

print("=== RECIBO TUA CANECA ===")
print(recibo)
EX 16

Projeto bônus: Amigo secreto 🎁

⭐⭐⭐ desafio
🎯 Objetivo

Resolver um problema clássico de sorteio (sem código pronto!).

🧭 Roteiro
  1. Monte a lista de participantes (input até "fim")
  2. Embaralhe com shuffle
  3. O truque: cada pessoa tira a SEGUINTE da lista embaralhada — e a última tira a primeira (círculo fechado, ninguém se tira!)
  4. Dica do círculo: nomes[(i + 1) % len(nomes)]
✅ Exemplo (varia!)
terminal
Diego tirou Ana
Ana tirou Carla
Carla tirou Bruno
Bruno tirou Diego
💡 Por que o % funciona?
Para 4 nomes, os índices são 0-3. No último (i=3), a conta (3+1) % 4 = 0 — volta ao começo! O resto da divisão (Semana 1!) fecha o círculo.
🔑 Ver solução

Só abra depois de tentar!

solucao_ex16.py
import random

nomes = []
while True:
    nome = input("Participante (ou 'fim'): ")
    if nome == "fim":
        break
    nomes.append(nome)

random.shuffle(nomes)

print("\n=== RESULTADO DO SORTEIO ===")
for i in range(len(nomes)):
    tira = nomes[i]
    recebe = nomes[(i + 1) % len(nomes)]
    print(f"{tira} tirou {recebe}")
