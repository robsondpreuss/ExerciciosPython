01

Criando e acessando listas

Conceito

Uma lista guarda vários valores numa única variável, entre colchetes:

exemplo.py
frutas = ["maçã", "banana", "uva"]
notas = [8.5, 7.0, 9.5, 6.0]
mistura = ["Ana", 25, True, 1.68]

Cada item tem uma posição chamada índice — e a contagem começa no 0! Em frutas: frutas[0] é "maçã", frutas[1] é "banana", frutas[2] é "uva". Índices negativos contam de trás para frente: frutas[-1] é o último item. E len(frutas) retorna o tamanho (3).

Mexendo na lista

⭐⭐ médio
🎯 Objetivo

ex04_metodos.py

EX 08

Soma e média da lista

⭐⭐ médio
🎯 Objetivo

Aplicar o padrão acumulador em listas — e conferir com as funções prontas.

🧭 Passo a passo
  1. Crie notas = [7.5, 8.0, 6.5, 9.0, 5.5]
  2. Some tudo com um for + acumulador
  3. Calcule a média dividindo por len(notas)
  4. Confira o resultado usando sum(notas)
✅ Saída esperada
terminal
Soma: 36.5
Média: 7.3
Média com sum(): 7.3
🔑 Ver solução

Só abra depois de tentar!

solucao_ex08.py
notas = [7.5, 8.0, 6.5, 9.0, 5.5]

soma = 0
for nota in notas:
    soma = soma + nota

media = soma / len(notas)
print(f"Soma: {soma}")
print(f"Média: {media:.1f}")

# Conferindo com as funções prontas:
print(f"Média com sum(): {sum(notas) / len(notas):.1f}")

04

Strings como sequências

Conceito

Surpresa: um texto se comporta como uma "lista de caracteres"! Tem índice (texto[0]), tamanho (len(texto)) e fatiamento: texto[inicio:fim] recorta um pedaço (o fim não entra, igual ao range!). E strings têm métodos próprios: .upper(), .lower(), .strip() (tira espaços das pontas), .replace(velho, novo) e .split() (quebra em lista de palavras).

💡 Dica
Na fatia [0:6], o índice 6 NÃO entra — pega do 0 ao 5. E omitir um lado significa "até o fim" ([-6:] = do sexto-de-trás até o final). O espaço também conta como caractere no len!

EX 14

Palíndromo 🔁

⭐⭐⭐ desafio
🎯 Objetivo

Verificar se uma palavra é igual de trás para frente (arara, ovo, radar...).

🧭 Passo a passo
  1. Peça uma palavra (com .lower() para ignorar maiúsculas)
  2. Inverta com a fatia mágica palavra[::-1]
  3. Compare a original com a invertida num if
✅ Exemplo de execução
terminal
Digite uma palavra: arara
arara é um palíndromo! 🔁
💡 A fatia mágica
[::-1] é uma fatia com passo -1: percorre o texto inteiro de trás para frente. O mesmo truque inverte listas!
🚀 Desafio extra
Frases como "a base do teto desaba" também são palíndromos — se ignorarmos os espaços. Use .replace(" ", "") antes de comparar.
🔑 Ver solução

Só abra depois de tentar!

solucao_ex14.py
palavra = input("Digite uma palavra: ").lower()
invertida = palavra[::-1]

if palavra == invertida:
    print(f"{palavra} é um palíndromo! 🔁")
else:
    print(f"{palavra} não é um palíndromo. (Invertida: {invertida})")

Separando pares e ímpares

⭐⭐ médio
🎯 Objetivo

Filtrar para DUAS listas ao mesmo tempo.

🧭 Passo a passo
  1. Crie numeros = [4, 7, 12, 9, 3, 18, 21, 6]
  2. Crie duas listas vazias: pares e ímpares
  3. Percorra: % 2 == 0 → vai para pares; senão → ímpares
✅ Saída esperada
terminal

🔑 Ver solução

Só abra depois de tentar!

solucao_ex16.py
numeros = [4, 7, 12, 9, 3, 18, 21, 6]
pares = []
impares = []

for n in numeros:
    if n % 2 == 0:
        pares.append(n)
    else:
        impares.append(n)

print(f"Pares: {pares}")
print(f"Ímpares: {impares}")

Projeto: Pedidos Tua Caneca v3 ☕

⭐⭐⭐ desafio

Sistema de pedidos com validação de estoque, carrinho e fechamento.

Aplique o desconto progressivo da Semana 2 sobre o total. Os projetos estão se encontrando! 😄
🔑 Ver solução

Só abra depois de tentar!

solucao_ex18.py
print("=== TUA CANECA - PEDIDOS ===")
CORES = ["branca", "preta", "azul", "amarela"]
PRECO = 25.00

print(f"Cores disponíveis: {CORES}")
carrinho = []

while True:
    cor = input("Cor da caneca (ou 'fim' para fechar): ")
    if cor == "fim":
        break
    if cor in CORES:
        carrinho.append(cor)
        print(f"✔ Caneca {cor} adicionada!")
    else:
        print("✖ Não temos essa cor.")

total = len(carrinho) * PRECO
print(f"Carrinho: {carrinho}")
print(f"{len(carrinho)} canecas — TOTAL: R$ {total:.2f}")

solucao_ex19.py
print("=== URNA ELETRÔNICA ===")
print("1 - Candidato A | 2 - Candidato B | 0 - Encerrar")

votos_a = 0
votos_b = 0

while True:
    voto = int(input("Seu voto: "))
    if voto == 0:
        break
    if voto == 1:
        votos_a = votos_a + 1
    elif voto == 2:
        votos_b = votos_b + 1
    else:
        print("Voto inválido!")

print(f"Candidato A: {votos_a} votos")
print(f"Candidato B: {votos_b} votos")

if votos_a > votos_b:
    print("🏆 Candidato A venceu!")
elif votos_b > votos_a:
    print("🏆 Candidato B venceu!")
else:
    print("Empate!")

Projeto bônus: Lista de tarefas no terminal ✅

⭐⭐⭐ desafio
🎯 Objetivo

Construir um mini-aplicativo completo sozinho (sem código pronto!).

🧭 Roteiro
  1. Crie a lista vazia tarefas = []
  2. Num while True, exiba o menu: 1-Adicionar · 2-Listar · 3-Remover · 4-Sair
  3. Implemente cada opção com if/elif (na remoção, verifique antes se a tarefa existe com in)
  4. A opção 4 encerra com break
✅ Exemplo de execução
terminal
1-Adicionar  2-Listar  3-Remover  4-Sair
Opção: 1
Nova tarefa: estudar python
1-Adicionar  2-Listar  3-Remover  4-Sair
Opção: 2
📋 Tarefas: ['estudar python']
1-Adicionar  2-Listar  3-Remover  4-Sair
Opção: 4

💡 Você percebeu?
Este projeto usa TUDO das 4 semanas: variáveis, input, conversão, condicionais, loop, break, listas, append, remove e in. É o seu primeiro aplicativo de verdade! 🎉
🔑 Ver solução

Só abra depois de tentar!

solucao_ex20.py
tarefas = []

while True:
    print()
    print("1-Adicionar  2-Listar  3-Remover  4-Sair")
    opcao = int(input("Opção: "))

    if opcao == 1:
        tarefa = input("Nova tarefa: ")
        tarefas.append(tarefa)
    elif opcao == 2:
        print(f"📋 Tarefas: {tarefas}")
    elif opcao == 3:
        tarefa = input("Qual tarefa remover? ")
        if tarefa in tarefas:
            tarefas.remove(tarefa)
        else:
            print("Tarefa não encontrada!")
    elif opcao == 4:
        print("Até logo!")
        break
    else:
        print("Opção inválida!")
