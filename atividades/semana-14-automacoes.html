01

O que é uma API?

Conceito

Uma API é o "garçom" de um sistema: você faz um pedido (requisição), ele leva para a cozinha (o servidor) e volta com o prato (a resposta — quase sempre em JSON, que você JÁ domina!). A biblioteca para fazer pedidos é a requests: instale com pip install requests.

Nosso primeiro garçom será o ViaCEP — uma API pública brasileira e gratuita que responde endereços a partir do CEP.

Consultas dinâmicas

Conceito

API de verdade se usa com dados do usuário: o CEP digitado entra na URL via f-string. E como a internet é traiçoeira (sem conexão, CEP inexistente...), as defesas das Semanas 2 e 7 entram em campo.

EX 03

Buscador de CEP 🔎

⭐⭐⭐ desafio
🎯 Objetivo

O consultor completo: input + URL dinâmica + validações.

🧭 Passo a passo
  1. Peça o CEP (só números, 8 dígitos)
  2. Monte a URL: f"https://viacep.com.br/ws/{cep}/json/"
  3. Defesa 1: status_code != 200 → CEP em formato inválido
  4. Defesa 2: o ViaCEP devolve {"erro": true} para CEP inexistente — teste if "erro" in dados
  5. Defesa 3: try/except em volta de tudo (sem internet não pode derrubar o programa!)
✅ Exemplo de execução
terminal
Digite o CEP (só números): 90010000
Rua dos Andradas, Centro Histórico
Porto Alegre - RS
🔑 Ver solução

Só abra depois de tentar!

solucao_ex03.py
import requests

cep = input("Digite o CEP (só números): ")

try:
    resposta = requests.get(f"https://viacep.com.br/ws/{cep}/json/", timeout=5)

    if resposta.status_code != 200:
        print("CEP em formato inválido!")
    else:
        dados = resposta.json()
        if "erro" in dados:
            print("CEP não encontrado!")
        else:
            print(f"{dados['logradouro']}, {dados['bairro']}")
            print(f"{dados['localidade']} - {dados['uf']}")
except Exception:
    print("Falha de conexão — verifique sua internet.")

Três camadas de defesa = programa profissional. O timeout=5 impede o programa de congelar para sempre se a API não responder.

solucao_ex05.py
import requests

def cotacao_dolar():
    url = "https://economia.awesomeapi.com.br/json/last/USD-BRL"
    resposta = requests.get(url, timeout=5)
    return float(resposta.json()["USDBRL"]["bid"])

dolar = cotacao_dolar()
print(f"Cotação atual: R$ {dolar:.2f}")

print("1-R$ → US$  2-US$ → R$")
opcao = input("Opção: ")
valor = float(input("Valor: "))

if opcao == "1":
    print(f"US$ {valor / dolar:.2f}")
elif opcao == "2":
    print(f"R$ {valor * dolar:.2f}")

API + todo o seu arsenal

Conceito

A mágica de 15 semanas de bagagem: a resposta da API é um dicionário — então TUDO funciona em cima dela: salvar em JSON (cache!), gravar relatórios em CSV, carimbar com datetime, processar em loop...

EX 06

Cache: salvando a consulta 📦

⭐⭐⭐ desafio
🎯 Objetivo

Guardar a resposta da API em JSON local com carimbo de data.

🧭 Passo a passo
  1. Consulte o dólar e monte um dicionário: cotação + datetime.now().strftime(...)
  2. Salve em cache_dolar.json
  3. Por que isso importa? Sem internet, seu programa pode usar a última cotação salva em vez de quebrar!
✅ Exemplo de execução
terminal
Cotação salva: R$ 5.43 em 12/06/2026 16:10 ✔
🔑 Ver solução

Só abra depois de tentar!

solucao_ex06.py
import json
import requests
from datetime import datetime

url = "https://economia.awesomeapi.com.br/json/last/USD-BRL"
cotacao = float(requests.get(url, timeout=5).json()["USDBRL"]["bid"])

cache = {
    "cotacao": cotacao,
    "consultado_em": datetime.now().strftime("%d/%m/%Y %H:%M")
}

with open("cache_dolar.json", "w", encoding="utf-8") as arquivo:
    json.dump(cache, arquivo, indent=2, ensure_ascii=False)

print(f"Cotação salva: R$ {cache['cotacao']:.2f} em {cache['consultado_em']} ✔")
EX 07

Lote de CEPs → CSV 📋

⭐⭐⭐ desafio
🎯 Objetivo

Várias consultas em loop, resultado em planilha.

🧭 Passo a passo
  1. Crie uma lista com 3 CEPs
  2. Para cada um: consulte, extraia cidade e UF, guarde num dicionário
  3. EDUCAÇÃO COM A API: time.sleep(1) entre as chamadas (Semana 9!)
  4. Grave tudo em enderecos.csv com DictWriter (Semana 13!)
✅ Exemplo de execução
terminal
90010-000 → Porto Alegre/RS
01310-100 → São Paulo/SP
20040-010 → Rio de Janeiro/RJ
enderecos.csv gerado ✔
🔑 Ver solução

Só abra depois de tentar!

solucao_ex07.py
import csv
import time
import requests

ceps = ["90010000", "01310100", "20040010"]
resultados = []

for cep in ceps:
    resposta = requests.get(f"https://viacep.com.br/ws/{cep}/json/", timeout=5)
    dados = resposta.json()
    resultados.append({
        "cep": dados["cep"],
        "cidade": dados["localidade"],
        "uf": dados["uf"]
    })
    print(f"{dados['cep']} → {dados['localidade']}/{dados['uf']}")
    time.sleep(1)   # pausa educada entre as chamadas

with open("enderecos.csv", "w", newline="", encoding="utf-8") as arquivo:
    escritor = csv.DictWriter(arquivo, fieldnames=["cep", "cidade", "uf"])
    escritor.writeheader()
    for linha in resultados:
        escritor.writerow(linha)

print("enderecos.csv gerado ✔")
05

Boas práticas de quem consome APIs

Conceito

O kit do consumidor responsável: timeout sempre (a API pode demorar), conferir o status antes de confiar, pausas entre chamadas em lote (martelar API gratuita é deselegante — e pode te bloquear!) e plano B offline (cache ou valor padrão).

EX 08

O plano B offline 🔌

⭐⭐ médio
🎯 Objetivo

Uma função de cotação que NUNCA quebra: API → cache → padrão.

🧭 Passo a passo
  1. Tente a API; se falhar, tente ler o cache_dolar.json; se nem ele existir, retorne 5.00 com aviso
  2. Teste os 3 caminhos (desligue o Wi-Fi para testar o segundo! 😄)
✅ Exemplo do plano B
terminal
(sem internet) Usando cache: R$ 5.43 de 12/06/2026 16:10
🔑 Ver solução

Só abra depois de tentar!

solucao_ex08.py
import json
import requests

def cotacao_segura():
    try:
        url = "https://economia.awesomeapi.com.br/json/last/USD-BRL"
        return float(requests.get(url, timeout=5).json()["USDBRL"]["bid"])
    except Exception:
        try:
            with open("cache_dolar.json", "r", encoding="utf-8") as arquivo:
                cache = json.load(arquivo)
            print(f"(sem internet) Usando cache: R$ {cache['cotacao']:.2f} de {cache['consultado_em']}")
            return cache["cotacao"]
        except FileNotFoundError:
            print("(sem internet e sem cache) Usando cotação padrão R$ 5.00")
            return 5.00

print(f"Cotação: R$ {cotacao_segura():.2f}")

Três degraus de fallback — guarde esta função: ela entra direto no projeto final da Semana 16!

EX 09

Projeto: Cadastro com endereço automático ☕📮

⭐⭐⭐ desafio
🎯 Objetivo

A Tua Caneca agora entrega: o cliente digita o CEP e o sistema preenche o endereço sozinho.

🧭 Requisitos
  1. Menu: 1-Cadastrar cliente · 2-Listar · 3-Salvar e sair
  2. No cadastro: nome + CEP → consulta no ViaCEP → confirma cidade/UF com o usuário
  3. Guarde cada cliente como dicionário (nome, cep, cidade, uf) e persista em clientes.json
  4. CEP não encontrado ou sem internet? Permita digitar a cidade manualmente (fallback!)
✅ Exemplo de execução
terminal
Nome: Ana
CEP: 90010000
Endereço encontrado: Porto Alegre - RS ✔
Cliente cadastrado!
🔑 Ver solução

Só abra depois de tentar!

solucao_ex09.py
import json
import requests

def consultar_cep(cep):
    try:
        resposta = requests.get(f"https://viacep.com.br/ws/{cep}/json/", timeout=5)
        dados = resposta.json()
        if resposta.status_code == 200 and "erro" not in dados:
            return dados["localidade"], dados["uf"]
    except Exception:
        pass
    return None, None

def carregar():
    try:
        with open("clientes.json", "r", encoding="utf-8") as arquivo:
            return json.load(arquivo)
    except FileNotFoundError:
        return []

clientes = carregar()

while True:
    print()
    print("1-Cadastrar  2-Listar  3-Salvar e sair")
    opcao = input("Opção: ")

    if opcao == "1":
        nome = input("Nome: ")
        cep = input("CEP: ")
        cidade, uf = consultar_cep(cep)
        if cidade is None:
            print("CEP não localizado — preencha manualmente.")
            cidade = input("Cidade: ")
            uf = input("UF: ")
        else:
            print(f"Endereço encontrado: {cidade} - {uf} ✔")
        clientes.append({"nome": nome, "cep": cep, "cidade": cidade, "uf": uf})
        print("Cliente cadastrado!")
    elif opcao == "2":
        for c in clientes:
            print(f"— {c['nome']}: {c['cidade']}/{c['uf']}")
    elif opcao == "3":
        with open("clientes.json", "w", encoding="utf-8") as arquivo:
            json.dump(clientes, arquivo, indent=2, ensure_ascii=False)
        break

Projeto: Monitor de moedas 📈

⭐⭐⭐ desafio
🎯 Objetivo

Painel de cotações com histórico em CSV.

🧭 Requisitos
  1. Consulte USD-BRL, EUR-BRL e BTC-BRL (a URL aceita: .../last/USD-BRL,EUR-BRL,BTC-BRL — uma chamada só!)
  2. Exiba um painel formatado
  3. Acrescente uma linha por moeda em historico.csv (modo append do CSV: abra com "a") com data e hora
  4. Rode em horários diferentes e veja o histórico crescer!
✅ Exemplo de execução

Dólar:   R$ 5.43

Bitcoin: R$ 580450.00

🔑 Ver solução

Só abra depois de tentar!

solucao_ex10.py
import csv
import requests
from datetime import datetime

url = "https://economia.awesomeapi.com.br/json/last/USD-BRL,EUR-BRL,BTC-BRL"
dados = requests.get(url, timeout=5).json()

agora = datetime.now().strftime("%d/%m/%Y %H:%M")
moedas = [
    ("Dólar", dados["USDBRL"]["bid"]),
    ("Euro", dados["EURBRL"]["bid"]),
    ("Bitcoin", dados["BTCBRL"]["bid"])
]

print(f"=== COTAÇÕES {agora} ===")
for nome, valor in moedas:
    print(f"{nome}: R$ {float(valor):.2f}")

with open("historico.csv", "a", newline="", encoding="utf-8") as arquivo:
    escritor = csv.writer(arquivo)
    for nome, valor in moedas:
        escritor.writerow([agora, nome, valor])

print("historico.csv atualizado ✔")

Projeto bônus: Calculadora de frete 📦

⭐⭐⭐ desafio
🎯 Objetivo

Frete por região a partir do CEP (sem código pronto!).

🧭 Roteiro
  1. Tabela de frete num dicionário por UF (ex.: RS 10 · SC/PR 15 · SP/RJ/MG/ES 20 · resto 30)
  2. O cliente digita o CEP → ViaCEP devolve a UF → o dicionário devolve o frete
  3. Mostre o resumo: cidade, UF e valor do frete
  4. Desafio: frete grátis para a mesma cidade da loja!
✅ Exemplo de execução
terminal
CEP de entrega: 88010000
Florianópolis/SC — Frete: R$ 15.00
🔑 Ver solução

Só abra depois de tentar!

solucao_ex11.py
import requests

FRETES = {"RS": 10.0, "SC": 15.0, "PR": 15.0,
          "SP": 20.0, "RJ": 20.0, "MG": 20.0, "ES": 20.0}

cep = input("CEP de entrega: ")

try:
    dados = requests.get(f"https://viacep.com.br/ws/{cep}/json/", timeout=5).json()
    if "erro" in dados:
        print("CEP não encontrado!")
    else:
        uf = dados["uf"]
        frete = FRETES.get(uf, 30.0)   # fora da tabela → 30
        if dados["localidade"] == "Porto Alegre":
            frete = 0.0   # frete grátis na cidade da loja!
        print(f"{dados['localidade']}/{uf} — Frete: R$ {frete:.2f}")
except Exception:
    print("Falha na consulta — tente novamente.")
