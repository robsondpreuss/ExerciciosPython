01

Criando e acessando dicionários

Conceito

A lista guarda valores por posição (0, 1, 2...). O dicionário guarda valores por nome — cada item é um par chave: valor, entre chaves:

exemplo.py
cliente = {
    "nome": "Ana",
    "idade": 28,
    "cidade": "Porto Alegre"
}

Para acessar, use a chave no lugar do índice: cliente["nome"] → "Ana". É como um cadastro: você não pede "o campo 2", você pede "a idade".

02

Percorrendo dicionários

Conceito

O for percorre as chaves de um dicionário. Para chave e valor juntos, use .items():

formas.py
for chave in dicionario:          # só as chaves
    print(chave, dicionario[chave])

for chave, valor in dicionario.items():   # os dois de uma vez
    print(chave, valor)

EX 08

Contando votos

⭐⭐⭐ desafio
🎯 Objetivo

Aprender o padrão contador com dicionário — um dos mais usados em análise de dados!

🧭 Passo a passo
  1. Crie votos = ["ana", "bruno", "ana", "carla", "ana", "bruno"]
  2. Crie contagem = {} vazio
  3. Percorra os votos: se o nome já está na contagem, some 1; senão, comece com 1
  4. Exiba o resultado
✅ Saída esperada
terminal
{'ana': 3, 'bruno': 2, 'carla': 1}
💡 O atalho profissional
O if/else inteiro vira UMA linha com o get: contagem[nome] = contagem.get(nome, 0) + 1 — "pegue o valor atual (ou 0 se não existir) e some 1".
🔑 Ver solução

Só abra depois de tentar!

solucao_ex08.py
votos = ["ana", "bruno", "ana", "carla", "ana", "bruno"]
contagem = {}

for nome in votos:
    if nome in contagem:
        contagem[nome] = contagem[nome] + 1
    else:
        contagem[nome] = 1

print(contagem)

# Versão enxuta com .get():
contagem2 = {}
for nome in votos:
    contagem2[nome] = contagem2.get(nome, 0) + 1
print(contagem2)

05

Tuplas: a lista que não muda

Conceito

A tupla é uma sequência como a lista, mas imutável — depois de criada, não dá para alterar. Usa parênteses: coordenada = (10, 25). Serve para dados que NÃO devem mudar (coordenadas, datas, configurações).

EX 14

Tupla e o TypeError

⭐ básico
🎯 Objetivo

Comprovar a imutabilidade na prática.

🧭 Passo a passo
  1. Crie e acesse uma tupla normalmente
  2. Depois tente ALTERAR um item (erro proposital!):
ex14_tupla.py
coordenada = (10, 25)

print(coordenada[0])
print(len(coordenada))

coordenada[0] = 99   # 💥
terminal
TypeError: 'tuple' object does not support item assignment
🔑 Ver solução

Só abra depois de tentar!

Acesso por índice e len() funcionam igual à lista — mas atribuir um valor a uma posição é proibido. Se você precisa de uma versão alterada, crie uma tupla NOVA. Essa "trava" protege dados que não deveriam mudar por acidente.

EX 15

Desempacotamento ✨

⭐⭐ médio
🎯 Objetivo

Distribuir os valores de uma tupla em variáveis — e fazer o truque da troca.

🧭 Passo a passo
  1. PREVEJA e execute:
ex15_desempacotar.py
coordenada = (10, 25)
x, y = coordenada
print(f"x = {x}, y = {y}")

a, b = 1, 2
a, b = b, a   # a famosa troca sem variável auxiliar!
print(f"a = {a}, b = {b}")
✅ Saída esperada
terminal
x = 10, y = 25
a = 2, b = 1
💡 Você já usava isso!
O for chave, valor in dicionario.items() da Parte 2 é desempacotamento: cada par vem como tupla e o for distribui nas duas variáveis. Tudo se conecta! 🤯

EX 16

Projeto: Estoque Tua Caneca ☕

⭐⭐⭐ desafio
🎯 Objetivo

Sistema de estoque com dicionário: consulta e venda com baixa automática.

🧭 Requisitos
  1. Crie estoque = {"branca": 10, "preta": 6, "azul": 0}
  2. Menu em loop: 1-Consultar · 2-Vender · 3-Sair
  3. Consultar: peça a cor e mostre a quantidade (cor inexistente → avise)
  4. Vender: só permita se a cor existir E tiver estoque; dê baixa de 1 unidade
✅ Exemplo de execução
terminal
1-Consultar  2-Vender  3-Sair
Opção: 2
Cor vendida: preta
Venda registrada! Restam 5
1-Consultar  2-Vender  3-Sair
Opção: 2
Cor vendida: azul
Sem estoque dessa cor!
🚀 Desafio extra
Na opção Consultar, se o usuário digitar "todas", exiba o estoque completo com .items().
🔑 Ver solução

Só abra depois de tentar!

solucao_ex16.py
estoque = {"branca": 10, "preta": 6, "azul": 0}

while True:
    print()
    print("1-Consultar  2-Vender  3-Sair")
    opcao = int(input("Opção: "))

    if opcao == 1:
        cor = input("Cor: ")
        if cor in estoque:
            print(f"Estoque de {cor}: {estoque[cor]}")
        else:
            print("Cor não cadastrada!")
    elif opcao == 2:
        cor = input("Cor vendida: ")
        if cor in estoque and estoque[cor] > 0:
            estoque[cor] = estoque[cor] - 1
            print(f"Venda registrada! Restam {estoque[cor]}")
        else:
            print("Sem estoque dessa cor!")
    elif opcao == 3:
        break
    else:
        print("Opção inválida!")

Projeto: Cadastro de clientes 📇

⭐⭐⭐ desafio
🎯 Objetivo

Montar um mini-CRM: lista de dicionários com menu completo.

🧭 Requisitos
  1. Comece com clientes = []
  2. Menu: 1-Adicionar (nome + telefone → dicionário → append) · 2-Listar todos · 3-Buscar por nome · 4-Sair
  3. Reaproveite a busca com flag do Exercício 13!
✅ Exemplo de execução
terminal
1-Adicionar  2-Listar  3-Buscar  4-Sair
Opção: 1
Nome: Ana
Telefone: (51) 98888-7777
Cliente cadastrado!
Opção: 2
— Ana: (51) 98888-7777
🔑 Ver solução

Só abra depois de tentar!

solucao_ex17.py
clientes = []

while True:
    print()
    print("1-Adicionar  2-Listar  3-Buscar  4-Sair")
    opcao = int(input("Opção: "))

    if opcao == 1:
        nome = input("Nome: ")
        telefone = input("Telefone: ")
        clientes.append({"nome": nome, "telefone": telefone})
        print("Cliente cadastrado!")
    elif opcao == 2:
        for cliente in clientes:
            print(f"— {cliente['nome']}: {cliente['telefone']}")
    elif opcao == 3:
        busca = input("Buscar: ")
        encontrado = False
        for cliente in clientes:
            if cliente["nome"] == busca:
                print(f"{cliente['nome']}: {cliente['telefone']}")
                encontrado = True
        if not encontrado:
            print("Cliente não encontrado!")
    elif opcao == 4:
        break
    else:
        print("Opção inválida!")

Projeto bônus: Tradutor v2

⭐⭐⭐ desafio
🎯 Objetivo

Melhorar o tradutor sozinho (sem código pronto!).

🧭 Roteiro
  1. Pegue seu tradutor do Exercício 7
  2. Coloque-o num loop que traduz até o usuário digitar "sair"
  3. Quando a palavra NÃO existir, mostre as palavras disponíveis (.keys()
  4. Bônus: ofereça cadastrar a tradução nova na hora (dicionários são mutáveis!)
✅ Exemplo de execução
terminal
Palavra (ou 'sair'): mesa
Não conheço! Palavras disponíveis: ['gato', 'cachorro', 'casa', 'livro', 'caneca']
Quer cadastrar? (sim/não): sim
Tradução de mesa: table
Cadastrada! ✔
🔑 Ver solução

Só abra depois de tentar!

solucao_ex18.py
dicionario = {"gato": "cat", "cachorro": "dog", "casa": "house",
              "livro": "book", "caneca": "mug"}

while True:
    palavra = input("Palavra (ou 'sair'): ").lower()
    if palavra == "sair":
        break
    if palavra in dicionario:
        print(f"Em inglês: {dicionario[palavra]}")
    else:
        print(f"Não conheço! Palavras disponíveis: {list(dicionario.keys())}")
        resposta = input("Quer cadastrar? (sim/não): ")
        if resposta == "sim":
            traducao = input(f"Tradução de {palavra}: ")
            dicionario[palavra] = traducao
            print("Cadastrada! ✔")
