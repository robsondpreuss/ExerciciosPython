01

Formulários: a porta de entrada de dados

Conceito

Nota de arquitetura: aqui o mesmo app Flask gera as telas E mexe no banco — é o estilo monolítico, ótimo para aprender. Nas Semanas 26-30 veremos a alternativa profissional: separar uma API REST (backend) de um frontend independente. Na Semana 19 suas páginas só MOSTRAVAM dados. Agora elas vão RECEBER. A ferramenta é o <form> do HTML, com dois métodos possíveis: GET (dados vão na URL — para buscas) e POST (dados vão "escondidos" no corpo — para cadastros e senhas). No Flask, o request.form lê o que foi enviado.

Garanta o Flask instalado (pip install flask, Semana 19) e use o loja.db das Semanas 21-22.

EX 01

Primeiro formulário 📝

⭐⭐ médio
🎯 Objetivo

Exibir um formulário numa página Flask.

🧭 Passo a passo
  1. Crie app.py com uma rota / que retorna um HTML com formulário
  2. O <form method="post"> e um <input name="nome"> são o básico
  3. Rode e veja o formulário no navegador (ainda não faz nada ao enviar — é o próximo passo)
app.py
from flask import Flask

app = Flask(__name__)

@app.route("/")
def inicio():
    return """
    <h1>Cadastro</h1>
    <form method="post" action="/salvar">
        <input name="nome" placeholder="Nome do produto">
        <button type="submit">Salvar</button>
    </form>
    """

app.run(debug=True)
✅ Saída esperada
terminal
(uma caixa de texto e um botão no navegador)
💡 GET vs POST
O action="/salvar" diz PARA ONDE os dados vão; o method="post" diz COMO (escondidos no corpo). Use POST para qualquer coisa que MUDA o banco ou tem dado sensível; GET fica para buscas e links.
EX 02

Recebendo os dados com request.form

⭐⭐ médio
🎯 Objetivo

Capturar o que o usuário enviou no formulário.

🧭 Passo a passo
  1. Importe from flask import Flask, request
  2. Crie a rota /salvar com methods=["POST"]
  3. Leia o campo com request.form.get("nome") e devolva uma confirmação
ex02_receber.py
from flask import Flask, request

app = Flask(__name__)

@app.route("/")
def inicio():
    return """<form method="post" action="/salvar">
        <input name="nome"><button>Enviar</button></form>"""

@app.route("/salvar", methods=["POST"])
def salvar():
    nome = request.form.get("nome")
    return f"<h1>Recebi: {nome}</h1><a href='/'>← Voltar</a>"

app.run(debug=True)
✅ Saída esperada
terminal
(digite "caneca azul", envie → "Recebi: caneca azul")
💡 O methods=["POST"]
Por padrão, rotas só aceitam GET. Para receber um formulário POST, a rota precisa declarar methods=["POST"]. O request.form.get("nome") busca o campo pelo name do input — é o .get() de dicionário da Semana 5!

EX 03

Cadastro que grava no banco 🗄️

⭐⭐⭐ desafio
🎯 Objetivo

Inserir no banco a partir do formulário — web (S19/23) encontra SQL (S21).

🧭 Passo a passo
  1. O formulário tem 3 campos: nome, preco, estoque
  2. Na rota /salvar: conecte, faça o INSERT com placeholders (?) e commit
  3. Sempre placeholders — segurança da Semana 21 vale na web também!
ex03_cadastro_banco.py
from flask import Flask, request
import sqlite3

app = Flask(__name__)

@app.route("/")
def inicio():
    return """
    <h1>Novo produto</h1>
    <form method="post" action="/salvar">
        <input name="nome" placeholder="Nome"><br>
        <input name="preco" placeholder="Preço"><br>
        <input name="estoque" placeholder="Estoque"><br>
        <button>Salvar</button>
    </form>
    """

@app.route("/salvar", methods=["POST"])
def salvar():
    nome = request.form.get("nome")
    preco = float(request.form.get("preco"))
    estoque = int(request.form.get("estoque"))

    conexao = sqlite3.connect("loja.db")
    cursor = conexao.cursor()
    cursor.execute(
        "INSERT INTO produtos (nome, preco, estoque) VALUES (?, ?, ?)",
        (nome, preco, estoque))
    conexao.commit()
    conexao.close()

    return f"<h1>{nome} cadastrado!</h1><a href='/'>← Novo</a>"

app.run(debug=True)
✅ Saída esperada
terminal
(preencha o form → produto gravado no banco de verdade!)
💡 Tudo se conecta
Formulário HTML (S19) → request.form (S23) → INSERT com placeholder (S21). Três semanas trabalhando juntas. O dado que você digitou no navegador agora está no banco, esperando para ser consultado por qualquer parte do sistema.

Listando o banco numa página

Conceito

O outro lado: trazer os dados do banco para a tela. É o SELECT da Semana 21 alimentando o loop de HTML da Semana 19 — a combinação que monta toda página de listagem que você já viu na internet.

EX 05

A página de produtos 🛍️

⭐⭐⭐ desafio
🎯 Objetivo

Mostrar todos os produtos do banco numa tabela HTML.

🧭 Passo a passo
  1. Rota /produtos: conecte, SELECT * FROM produtos, fetchall
  2. Monte as linhas da tabela num loop (acumulador de string — Semanas 3 e 19)
  3. Devolva uma <table> com cabeçalho + as linhas
ex05_listar.py
from flask import Flask
import sqlite3

app = Flask(__name__)

@app.route("/produtos")
def produtos():
    conexao = sqlite3.connect("loja.db")
    cursor = conexao.cursor()
    cursor.execute("SELECT id, nome, preco, estoque FROM produtos")
    linhas = cursor.fetchall()
    conexao.close()

    html = "<h1>Produtos</h1><table border='1' cellpadding='6'>"
    html += "<tr><th>ID</th><th>Nome</th><th>Preço</th><th>Estoque</th></tr>"
    for id, nome, preco, estoque in linhas:
        html += f"<tr><td>{id}</td><td>{nome}</td><td>R$ {preco:.2f}</td><td>{estoque}</td></tr>"
    html += "</table>"
    return html

app.run(debug=True)
✅ Saída esperada
terminal
(uma tabela com todos os produtos do banco no navegador!)
💡 SELECT + loop = listagem
Toda lista que você vê na web — produtos numa loja, posts numa rede, e-mails na caixa — é isso: um SELECT no banco e um loop montando o HTML. Você acabou de aprender o padrão mais comum da programação web.

Botão de excluir 🗑️

⭐⭐⭐ desafio

  2. Crie a rota /excluir/<int:id>: DELETE WHERE id=? e redirect("/produtos")

Em sistemas REAIS, excluir por um link GET é arriscado (um robô ou um F5 pode disparar). O jeito profissional usa um pequeno formulário POST com confirmação. Para aprender, o link serve — mas guarde: ações que mudam o banco deveriam ser POST.
🔑 Ver solução

Só abra depois de tentar!

solucao_ex07.py
from flask import Flask, redirect
import sqlite3

app = Flask(__name__)

@app.route("/produtos")
def produtos():
    conexao = sqlite3.connect("loja.db")
    cursor = conexao.cursor()
    cursor.execute("SELECT id, nome, preco FROM produtos")
    linhas = cursor.fetchall()
    conexao.close()

    html = "<h1>Produtos</h1><table border='1' cellpadding='6'>"
    for id, nome, preco in linhas:
        html += (f"<tr><td>{nome}</td><td>R$ {preco:.2f}</td>"
                 f"<td><a href='/excluir/{id}'>excluir</a></td></tr>")
    html += "</table>"
    return html

@app.route("/excluir/<int:id>")
def excluir(id):
    conexao = sqlite3.connect("loja.db")
    cursor = conexao.cursor()
    cursor.execute("DELETE FROM produtos WHERE id = ?", (id,))
    conexao.commit()
    conexao.close()
    return redirect("/produtos")

app.run(debug=True)

Editar: fechando o CRUD

Conceito

A operação mais elaborada: editar precisa de DUAS rotas com o mesmo endereço. No GET, você BUSCA o produto e mostra um formulário JÁ PREENCHIDO. No POST, você recebe as mudanças e faz o UPDATE. É o request.method que distingue os dois.

Salvando a edição (UPDATE)

⭐⭐⭐ desafio
🎯 Objetivo

Receber o formulário de edição e atualizar o banco.

🧭 Passo a passo
  1. Adicione methods=["GET", "POST"] à rota /editar/<int:id>
  2. Use if request.method == "POST": aí faz o UPDATE com os dados do form e redireciona

✅ Saída esperada
terminal
(edita os campos → Atualizar → volta para a lista já alterada)
💡 Uma rota, dois comportamentos
O request.method permite a MESMA URL servir o formulário (GET) e processar o envio (POST). É o padrão clássico de edição na web — e agora seu CRUD está completo: Create, Read, Update, Delete, todos pela web!
🔑 Ver solução

Só abra depois de tentar!

solucao_ex09.py
from flask import Flask, request, redirect
import sqlite3

app = Flask(__name__)

@app.route("/editar/<int:id>", methods=["GET", "POST"])
def editar(id):
    conexao = sqlite3.connect("loja.db")
    cursor = conexao.cursor()

    if request.method == "POST":
        nome = request.form.get("nome")
        preco = float(request.form.get("preco"))
        estoque = int(request.form.get("estoque"))
        cursor.execute(
            "UPDATE produtos SET nome=?, preco=?, estoque=? WHERE id=?",
            (nome, preco, estoque, id))
        conexao.commit()
        conexao.close()
        return redirect("/produtos")

    cursor.execute("SELECT nome, preco, estoque FROM produtos WHERE id = ?", (id,))
    nome, preco, estoque = cursor.fetchone()
    conexao.close()
    return f"""
    <form method="post" action="/editar/{id}">
        <input name="nome" value="{nome}"><br>
        <input name="preco" value="{preco}"><br>
        <input name="estoque" value="{estoque}"><br>
        <button>Atualizar</button>
    </form>
    """

app.run(debug=True)

app.py
from flask import Flask, request, redirect
import sqlite3

app = Flask(__name__)

def conectar():
    conexao = sqlite3.connect("loja.db")
    conexao.execute("""
        CREATE TABLE IF NOT EXISTS produtos (
            id INTEGER PRIMARY KEY AUTOINCREMENT,
            nome TEXT, preco REAL, estoque INTEGER
        )
    """)
    return conexao

@app.route("/")
def painel():
    conexao = conectar()
    cursor = conexao.cursor()
    cursor.execute("SELECT id, nome, preco, estoque FROM produtos ORDER BY nome")
    linhas = cursor.fetchall()
    conexao.close()

    tabela = "<table border='1' cellpadding='6'><tr><th>Nome</th><th>Preço</th><th>Estoque</th><th>Ações</th></tr>"
    for id, nome, preco, estoque in linhas:
        tabela += (f"<tr><td>{nome}</td><td>R$ {preco:.2f}</td><td>{estoque}</td>"
                   f"<td><a href='/editar/{id}'>editar</a> | "
                   f"<a href='/excluir/{id}'>excluir</a></td></tr>")
    tabela += "</table>"

    return f"""
    <html><head><title>Admin Tua Caneca</title>
    <style>
      body {{ font-family: Arial; background: #F5F8FC; margin: 40px; }}
      h1 {{ color: #3776AB; }}
      input {{ padding: 6px; margin: 3px; }}
      table {{ background: white; }}
    </style></head><body>
    <h1>☕ Painel Tua Caneca</h1>
    <form method="post" action="/salvar">
        <input name="nome" placeholder="Nome">
        <input name="preco" placeholder="Preço">
        <input name="estoque" placeholder="Estoque">
        <button>Cadastrar</button>
    </form><br>
    {tabela}
    </body></html>
    """

@app.route("/salvar", methods=["POST"])
def salvar():
    nome = request.form.get("nome", "").strip()
    if not nome:
        return redirect("/")
    try:
        preco = float(request.form.get("preco"))
        estoque = int(request.form.get("estoque"))
    except (ValueError, TypeError):
        return redirect("/")
    conexao = conectar()
    conexao.execute("INSERT INTO produtos (nome, preco, estoque) VALUES (?, ?, ?)",
                    (nome, preco, estoque))
    conexao.commit()
    conexao.close()
    return redirect("/")

@app.route("/editar/<int:id>", methods=["GET", "POST"])
def editar(id):
    conexao = conectar()
    cursor = conexao.cursor()
    if request.method == "POST":
        nome = request.form.get("nome")
        preco = float(request.form.get("preco"))
        estoque = int(request.form.get("estoque"))
        cursor.execute("UPDATE produtos SET nome=?, preco=?, estoque=? WHERE id=?",
                       (nome, preco, estoque, id))
        conexao.commit()
        conexao.close()
        return redirect("/")
    cursor.execute("SELECT nome, preco, estoque FROM produtos WHERE id=?", (id,))
    nome, preco, estoque = cursor.fetchone()
    conexao.close()
    return f"""
    <form method="post" action="/editar/{id}">
        <input name="nome" value="{nome}">
        <input name="preco" value="{preco}">
        <input name="estoque" value="{estoque}">
        <button>Atualizar</button>
    </form> <a href="/">cancelar</a>
    """

@app.route("/excluir/<int:id>")
def excluir(id):
    conexao = conectar()
    conexao.execute("DELETE FROM produtos WHERE id=?", (id,))
    conexao.commit()
    conexao.close()
    return redirect("/")

from flask import Flask, request
import sqlite3

app = Flask(__name__)

@app.route("/vender", methods=["GET", "POST"])
def vender():
    if request.method == "POST":
        nome = request.form.get("nome")
        qtd = int(request.form.get("qtd"))

        conexao = sqlite3.connect("loja.db")
        cursor = conexao.cursor()
        cursor.execute("SELECT estoque FROM produtos WHERE nome = ?", (nome,))
        r = cursor.fetchone()

        if r is None:
            msg = "Produto não encontrado!"
        elif r[0] < qtd:
            msg = f"Estoque insuficiente! Disponível: {r[0]}"
        else:
            cursor.execute(
                "UPDATE produtos SET estoque = estoque - ? WHERE nome = ?",
                (qtd, nome))
            conexao.commit()
            msg = f"Venda registrada! Restam {r[0] - qtd}"
        conexao.close()
        return f"<h1>{msg}</h1><a href='/vender'>← Nova venda</a>"

    return """
    <h1>Registrar venda</h1>
    <form method="post" action="/vender">
        <input name="nome" placeholder="Produto">
        <input name="qtd" placeholder="Quantidade">
        <button>Vender</button>
    </form>
    """

app.run(debug=True)
