01

Herança: classes que herdam de classes

Conceito

Quando uma classe é "um tipo de" outra, ela pode herdar: class Cachorro(Animal): faz Cachorro receber DE GRAÇA tudo que Animal tem — e ainda poder adicionar ou modificar o que quiser.

EX 01

A primeira herança

⭐⭐ médio
🎯 Objetivo

Herdar atributos e métodos sem reescrever nada.

🧭 Passo a passo
  1. Digite e execute — repare que Cachorro está VAZIO (pass) e mesmo assim funciona:
ex01_heranca.py
class Animal:
    def __init__(self, nome):
        self.nome = nome

    def comer(self):
        print(f"{self.nome} está comendo")

class Cachorro(Animal):
    pass    # nada aqui... e mesmo assim herda tudo!

rex = Cachorro("Rex")
rex.comer()
✅ Saída esperada
terminal
Rex está comendo
💡 Vocabulário
Animal é a classe mãe (ou "base"); Cachorro é a filha. O pass significa "nada a declarar" — a filha já nasce rica. 😄
EX 02

Cada um com seu som

⭐⭐ médio
🎯 Objetivo

Sobrescrever: a filha redefine um método da mãe.

🧭 Passo a passo
  1. Dê um fazer_som genérico para Animal
  2. Sobrescreva em Cachorro (Au au!) e em Gato (Miau!)
  3. Percorra uma lista mista chamando o MESMO método
ex02_sons.py
class Animal:
    def __init__(self, nome):
        self.nome = nome

    def fazer_som(self):
        print(f"{self.nome} fez um som qualquer")

class Cachorro(Animal):
    def fazer_som(self):
        print(f"{self.nome}: Au au!")

class Gato(Animal):
    def fazer_som(self):
        print(f"{self.nome}: Miau!")

animais = [Cachorro("Rex"), Gato("Mimi"), Animal("Bicho")]
for animal in animais:
    animal.fazer_som()
✅ Saída esperada
terminal
Rex: Au au!
Mimi: Miau!
Bicho fez um som qualquer
💡 Isso tem nome chique
O mesmo comando (animal.fazer_som()) se comportando diferente conforme o objeto se chama polimorfismo. Solte essa palavra numa entrevista. 😎
EX 03

super(): herdar E acrescentar

⭐⭐⭐ desafio
🎯 Objetivo

A filha aproveita o __init__ da mãe e adiciona o seu.

🧭 Passo a passo
  1. Gato vai ter nome (como todo Animal) MAIS cor
  2. No __init__ da filha: primeiro super().__init__(nome) (chama o init da mãe), depois self.cor = cor
✅ Exemplo de execução
terminal
Mimi é um gato cinza
Mimi: Miau!
🔑 Ver solução

Só abra depois de tentar!

solucao_ex03.py
class Animal:
    def __init__(self, nome):
        self.nome = nome

class Gato(Animal):
    def __init__(self, nome, cor):
        super().__init__(nome)   # a mãe cuida do nome
        self.cor = cor           # a filha cuida da cor

    def fazer_som(self):
        print(f"{self.nome}: Miau!")

mimi = Gato("Mimi", "cinza")
print(f"{mimi.nome} é um gato {mimi.cor}")
mimi.fazer_som()

Sem o super().__init__(nome), o atributo nome nunca seria criado — a filha sobrescreveu o init da mãe e precisa chamá-la de volta explicitamente.

Composição: objetos dentro de objetos

Conceito

Herança é "Cachorro É UM Animal". Composição é "Pedido TEM Produtos": um objeto guarda OUTROS objetos num atributo (geralmente uma lista). Os dois juntos modelam qualquer sistema do mundo real.

- azulejo — R$ 40.00

solucao_ex04.py
class Produto:
    def __init__(self, nome, preco):
        self.nome = nome
        self.preco = preco

    def __str__(self):
        return f"{self.nome} — R$ {self.preco:.2f}"

class Pedido:
    def __init__(self, cliente):
        self.cliente = cliente
        self.itens = []

    def adicionar(self, produto):
        self.itens.append(produto)

    def total(self):
        soma = 0
        for item in self.itens:
            soma = soma + item.preco
        return soma

    def resumo(self):
        print(f"Pedido de {self.cliente}:")
        for item in self.itens:
            print(f"- {item}")
        print(f"TOTAL: R$ {self.total():.2f}")

pedido = Pedido("Ana")
pedido.adicionar(Produto("caneca branca", 25.0))
pedido.adicionar(Produto("azulejo", 40.0))
pedido.resumo()
03

JSON: o formato universal

Conceito

JSON é basicamente um dicionário do Python escrito como texto — e é a língua franca dos dados: sites, APIs, aplicativos e configurações falam JSON. O módulo json traduz nos dois sentidos: dumps/dump (Python → JSON) e loads/load (JSON → Python).

EX 05

Dicionário vira texto

⭐⭐ médio
🎯 Objetivo

Conhecer a cara do JSON com dumps.

🧭 Passo a passo
  1. Digite e execute:
ex05_dumps.py
import json

cliente = {"nome": "Ana", "idade": 28, "cursos": ["Python", "Excel"]}

texto = json.dumps(cliente, indent=2, ensure_ascii=False)
print(texto)
print(type(texto))
✅ Saída esperada
terminal
{
  "nome": "Ana",
  "idade": 28,
  "cursos": [
    "Python",
    "Excel"
  ]
}
<class 'str'>
💡 Os dois ajudantes
indent=2 formata bonito (sem ele, sai tudo numa linha). ensure_ascii=False preserva acentos — sem ele, "João" vira "Jo\u00e3o". Use os dois sempre!

04

Objetos ↔ JSON

Conceito

O json não sabe gravar objetos seus diretamente — mas sabe gravar dicionários. A ponte é o padrão to_dict(): objeto → dict → JSON na ida; JSON → dict → objeto na volta.

EX 09

A ponte to_dict 🌉

⭐⭐⭐ desafio
🎯 Objetivo

Salvar e reconstruir objetos via JSON — o padrão do projeto final!

🧭 Passo a passo
  1. Na classe Produto, crie to_dict(self) que retorna {"nome": self.nome, ...}
  2. Salvar: converta cada objeto da lista com to_dict e grave a lista de dicts
  3. Carregar: para cada dict lido, crie Produto(d["nome"], d["preco"], d["estoque"])
✅ Saída da carga
terminal
Objetos reconstruídos:
caneca branca — R$ 25.00 (10 un.)
azulejo — R$ 40.00 (5 un.)
🔑 Ver solução

Só abra depois de tentar!

solucao_ex09.py
import json

class Produto:
    def __init__(self, nome, preco, estoque):
        self.nome = nome
        self.preco = preco
        self.estoque = estoque

    def to_dict(self):
        return {"nome": self.nome, "preco": self.preco, "estoque": self.estoque}

    def __str__(self):
        return f"{self.nome} — R$ {self.preco:.2f} ({self.estoque} un.)"

# --- salvar ---
produtos = [Produto("caneca branca", 25.0, 10), Produto("azulejo", 40.0, 5)]

dados = []
for p in produtos:
    dados.append(p.to_dict())

with open("estoque.json", "w", encoding="utf-8") as arquivo:
    json.dump(dados, arquivo, indent=2, ensure_ascii=False)

# --- carregar ---
with open("estoque.json", "r", encoding="utf-8") as arquivo:
    lidos = json.load(arquivo)

recuperados = []
for d in lidos:
    recuperados.append(Produto(d["nome"], d["preco"], d["estoque"]))

print("Objetos reconstruídos:")
for p in recuperados:
    print(p)

import json

def salvar_contatos(contatos):
    with open("contatos.json", "w", encoding="utf-8") as arquivo:

                encontrado = True
        if not encontrado:
            print("Não encontrado!")

solucao_ex11.py
import json

class Produto:
    def __init__(self, nome, preco, estoque):
        self.nome = nome
        self.preco = preco
        self.estoque = estoque

    def vender(self, qtd):
        if qtd <= 0 or qtd > self.estoque:
            print("Quantidade inválida!")
            return False
        self.estoque = self.estoque - qtd
        print(f"Vendido: {qtd}x {self.nome}")
        return True

    def to_dict(self):
        return {"nome": self.nome, "preco": self.preco, "estoque": self.estoque}

    def __str__(self):
        return f"{self.nome} — R$ {self.preco:.2f} ({self.estoque} un.)"

def carregar():
    try:
        with open("catalogo.json", "r", encoding="utf-8") as arquivo:
            dados = json.load(arquivo)
        produtos = []
        for d in dados:
            produtos.append(Produto(d["nome"], d["preco"], d["estoque"]))
        return produtos
    except FileNotFoundError:
        return [Produto("caneca branca", 25.0, 10), Produto("azulejo", 40.0, 5)]

def salvar(produtos):
    dados = []
    for p in produtos:
        dados.append(p.to_dict())
    with open("catalogo.json", "w", encoding="utf-8") as arquivo:
        json.dump(dados, arquivo, indent=2, ensure_ascii=False)

produtos = carregar()

while True:
    print()
    print("1-Listar  2-Adicionar  3-Vender  4-Salvar e sair")
    opcao = int(input("Opção: "))

    if opcao == 1:
        for p in produtos:
            print(p)
    elif opcao == 2:
        nome = input("Nome: ")
        preco = float(input("Preço: R$ "))
        estoque = int(input("Estoque: "))
        produtos.append(Produto(nome, preco, estoque))
    elif opcao == 3:
        nome = input("Produto: ")
        qtd = int(input("Quantidade: "))
        encontrado = False
        for p in produtos:
            if p.nome == nome:
                p.vender(qtd)
                encontrado = True
        if not encontrado:
            print("Produto não existe!")
    elif opcao == 4:
        salvar(produtos)
        break

Projeto: Turma com classe Aluno 🎓

⭐⭐⭐ desafio
🎯 Objetivo

A classe Aluno da Semana 10 ganha persistência (e o JSON guarda a lista de notas numa boa!).

🧭 Requisitos
  1. Use a classe Aluno (nome + lista de notas + media + situacao)
  2. to_dict inclui a lista: {"nome": ..., "notas": self.notas}
  3. Menu: adicionar aluno, lançar nota, boletim (nome, média, situação), salvar e sair
  4. Repare: o JSON salva a LISTA de notas sem esforço — tente fazer isso com CSV caseiro! 😅
✅ Boletim
terminal
Ana: média 8.0 — Aprovado
Bruno: média 5.5 — Recuperação
🔑 Ver solução

Só abra depois de tentar!

solucao_ex12.py
import json

class Aluno:
    def __init__(self, nome, notas=None):
        self.nome = nome
        if notas is None:
            self.notas = []
        else:
            self.notas = notas

    def adicionar_nota(self, nota):
        self.notas.append(nota)

    def media(self):
        if len(self.notas) == 0:
            return 0
        return sum(self.notas) / len(self.notas)

    def situacao(self):
        if self.media() >= 7:
            return "Aprovado"
        return "Recuperação"

    def to_dict(self):
        return {"nome": self.nome, "notas": self.notas}

def carregar():
    try:
        with open("turma.json", "r", encoding="utf-8") as arquivo:
            dados = json.load(arquivo)
        return [Aluno(d["nome"], d["notas"]) for d in dados]
    except FileNotFoundError:
        return []

def salvar(turma):
    dados = [aluno.to_dict() for aluno in turma]
    with open("turma.json", "w", encoding="utf-8") as arquivo:
        json.dump(dados, arquivo, indent=2, ensure_ascii=False)

turma = carregar()

while True:
    print()
    print("1-Novo aluno  2-Lançar nota  3-Boletim  4-Salvar e sair")
    opcao = int(input("Opção: "))

    if opcao == 1:
        turma.append(Aluno(input("Nome: ")))
    elif opcao == 2:
        nome = input("Aluno: ")
        for aluno in turma:
            if aluno.nome == nome:
                aluno.adicionar_nota(float(input("Nota: ")))
    elif opcao == 3:
        for aluno in turma:
            print(f"{aluno.nome}: média {aluno.media():.1f} — {aluno.situacao()}")
    elif opcao == 4:
        salvar(turma)
        break

Duas novidades de gente grande na solução: o parâmetro notas=None (permite criar aluno novo OU reconstruir do JSON) e a list comprehension [aluno.to_dict() for aluno in turma] — o for de uma linha. Pesquise, você está pronto! 😉

class Produto:
    def __init__(self, nome, preco, estoque):
        self.nome = nome
        self.preco = preco
        self.estoque = estoque

    def __str__(self):
        return f"{self.nome} — R$ {self.preco:.2f} ({self.estoque} un.)"

class CanecaPersonalizada(Produto):
    def __init__(self, nome, preco, estoque):
        super().__init__(nome, preco + 10.0, estoque)

    def __str__(self):
        return super().__str__() + " (personalizada)"

class AzulejoDecorado(Produto):
    def __init__(self, nome, preco, estoque):
        super().__init__(nome, preco + 15.0, estoque)

    def __str__(self):
        return super().__str__() + " (decorado)"

catalogo = [
    CanecaPersonalizada("caneca dia das mães", 25.0, 20),
