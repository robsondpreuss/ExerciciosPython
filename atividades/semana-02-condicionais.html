01

Operadores de comparação

Conceito

Comparações fazem perguntas cuja resposta é sempre True (verdadeiro) ou False (falso) — o tipo bool que você conheceu na Semana 1.

OperadorPerguntaExemploResultado
==é igual a?5 == 5True
!=é diferente de?5 != 3True
>é maior que?5 > 8False
<é menor que?5 < 8True

02

if / else: o primeiro desvio

Conceito

A estrutura if executa um bloco de código somente se a condição for True. O else define o que fazer caso contrário:

estrutura.py
if condicao:
    # executa se a condição for True
    print("Sim!")
else:
    # executa se a condição for False
    print("Não!")

Duas regras visuais essenciais: (1) os dois pontos : no final da linha do if e do else; (2) a indentação — o código "de dentro" precisa estar deslocado 4 espaços para a direita. É assim que o Python sabe o que pertence ao if!

03

elif: vários caminhos

Conceito

Quando há mais de duas possibilidades, usamos elif (abreviação de "else if"). O Python testa as condições de cima para baixo e executa apenas o PRIMEIRO bloco verdadeiro:

estrutura.py
if condicao1:
    # caminho 1
elif condicao2:
    # caminho 2
elif condicao3:
    # caminho 3
else:
    # se nenhuma for True

⚠️ A ordem das condições importa — você vai comprovar isso no Exercício 9!

Triângulo: existe e qual é? 📐

⭐⭐⭐ desafio
🎯 Objetivo

Combinar and com condicionais aninhadas num problema clássico.

Regras: três lados formam um triângulo se a soma de QUAISQUER dois for maior que o terceiro. Se existir: 3 lados iguais → equilátero · 2 iguais → isósceles · todos diferentes → escaleno.

🧭 Passo a passo
  1. Peça os lados a, b e c
  2. Primeiro if: verifica a existência com 3 condições ligadas por and
  3. DENTRO dele, classifique com if/elif/else
  4. Teste com (3, 4, 5) → escaleno e com (1, 1, 10) → não existe
✅ Exemplo de execução
terminal
Lado a: 5
Lado b: 5
Lado c: 8
Triângulo ISÓSCELES (2 lados iguais)
🔑 Ver solução

Só abra depois de tentar!

solucao_ex18.py
a = float(input("Lado a: "))
b = float(input("Lado b: "))
c = float(input("Lado c: "))

if a + b > c and a + c > b and b + c > a:
    if a == b and b == c:
        print("Triângulo EQUILÁTERO (3 lados iguais)")
    elif a == b or a == c or b == c:
        print("Triângulo ISÓSCELES (2 lados iguais)")
    else:
        print("Triângulo ESCALENO (3 lados diferentes)")
else:
    print("Esses lados não formam um triângulo!")

Contexto: a loja de canecas agora dá desconto por volume: 20 canecas ou mais → 15% · 10 ou mais → 10% · abaixo disso → sem desconto. Cada caneca custa R$ 25,00.

  1. Peça a quantidade e calcule o subtotal
  2. Defina o desconto com if/elif/else (atenção à ordem: teste o 20 primeiro!)

terminal

Quantidade de canecas: 12
Subtotal: R$ 300.00
Desconto: 10%

Adicione frete grátis para pedidos acima de R$ 250 (senão, frete de R$ 15).
🔑 Ver solução

Só abra depois de tentar!

solucao_ex20.py
print("=== TUA CANECA - ORÇAMENTO v2 ===")

print("=== ESTACIONAMENTO ROTATIVO ===")

horas = int(input("Quantas horas o carro ficou? "))

if horas <= 1:
    valor = 8.00
else:
    valor = 8.00 + (horas - 1) * 5.00

# Desafio extra — diária máxima:
if valor > 40:
    valor = 40.00

print(f"Tempo: {horas}h")
print(f"Valor a pagar: R$ {valor:.2f}")
