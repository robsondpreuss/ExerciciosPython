01

O primeiro site da sua vida

Conceito

Instale com pip install flask. O Flask transforma funções Python em páginas web: o decorador @app.route("/") diz "quando alguém visitar este endereço, execute esta função e mostre o que ela retornar". O app.run() liga o servidor — acesse http://localhost:5000 no navegador, e pare com Ctrl+C no terminal.

EX 01

Olá, web! 🌐

⭐⭐ médio
🎯 Objetivo

Colocar um servidor no ar em 7 linhas.

🧭 Passo a passo
  1. Crie e execute site.py:
  2. O terminal mostra "Running on http://127.0.0.1:5000" — abra esse endereço no navegador!
  3. Deixe o terminal rodando; para encerrar, Ctrl+C
site.py
from flask import Flask

app = Flask(__name__)

@app.route("/")
def inicio():
    return "<h1>Olá, web! Meu primeiro site em Python 🐍</h1>"

app.run(debug=True)
✅ Saída esperada
terminal
 * Running on http://127.0.0.1:5000
(e o título gigante no navegador!)
💡 O que é debug=True?
O modo desenvolvedor: o servidor REINICIA sozinho a cada alteração salva no código (sem ele, você teria que parar e rodar de novo toda hora). E "localhost" / "127.0.0.1" significam "esta máquina" — seu site é só seu, por enquanto. 😉

EX 04

A tabuada vira página 🤯

⭐⭐⭐ desafio
🎯 Objetivo

Um loop da Semana 3 gerando HTML — e o conversor <int:n>.

🧭 Passo a passo
  1. <int:n> já entrega o valor CONVERTIDO para inteiro
  2. Monte o HTML num acumulador de string dentro do for (Semana 3 + 4!):
ex04_tabuada.py
@app.route("/tabuada/<int:n>")
def tabuada(n):
    linhas = ""
    for i in range(1, 11):
        linhas = linhas + f"<li>{n} x {i} = {n * i}</li>"
    return f"<h1>Tabuada do {n}</h1><ul>{linhas}</ul>"
✅ Saída esperada
terminal
(/tabuada/7 → a tabuada inteira em lista HTML!)
🔑 Ver solução

Só abra depois de tentar!

Visite /tabuada/7, /tabuada/9... A função roda A CADA visita, gerando a página na hora — é por isso que se chama página dinâmica. E se você visitar /tabuada/banana? O <int:n> rejeita e devolve 404 — validação de graça!

EX 05

O catálogo no navegador 🛍️

⭐⭐⭐ desafio
🎯 Objetivo

Ler o JSON e montar a página de produtos.

🧭 Passo a passo
  1. Garanta um catalogo.json com 3 produtos (nome, preco, estoque)
  2. Na rota /catalogo: carregue o JSON, monte um item HTML por produto no loop
  3. Capriche: mostre "ESGOTADO" quando o estoque for 0 (Semana 2 na web!)
✅ Saída esperada
terminal
(/catalogo → a lista de produtos com preços!)
🔑 Ver solução

Só abra depois de tentar!

solucao_ex05.py
import json
from flask import Flask

app = Flask(__name__)

@app.route("/catalogo")
def catalogo():
    with open("catalogo.json", "r", encoding="utf-8") as arquivo:
        produtos = json.load(arquivo)

    itens = ""
    for p in produtos:
        if p["estoque"] > 0:
            situacao = f"{p['estoque']} em estoque"
        else:
            situacao = "ESGOTADO"
        itens = itens + f"<li><b>{p['nome']}</b> — R$ {p['preco']:.2f} ({situacao})</li>"

    return f"<h1>☕ Catálogo Tua Caneca</h1><ul>{itens}</ul>"

app.run(debug=True)

EX 06

A API da Tua Caneca

⭐⭐⭐ desafio
🎯 Objetivo

Servir o catálogo como JSON.

🧭 Passo a passo
  1. Importe o jsonify: from flask import Flask, jsonify
  2. Crie a rota /api/produtos retornando jsonify(produtos)
  3. Visite no navegador: JSON puro, formatado, oficial!
ex06_api.py
from flask import Flask, jsonify
import json

app = Flask(__name__)

@app.route("/api/produtos")
def api_produtos():
    with open("catalogo.json", "r", encoding="utf-8") as arquivo:
        produtos = json.load(arquivo)
    return jsonify(produtos)

app.run(debug=True)
✅ Saída esperada
terminal
(/api/produtos → seu catálogo em JSON, como uma API de verdade!)
💡 Por que /api/ no nome?
Convenção: rotas de páginas servem HTML para HUMANOS; rotas /api/ servem JSON para PROGRAMAS. O mesmo dado, dois públicos.

solucao_ex08.py
def pagina(titulo, conteudo):
    return f"""
    <html><head><title>{titulo}</title>
    <style>
      body {{ font-family: Arial; background: #F5F8FC; margin: 40px; }}
      h1 {{ color: #3776AB; }}
      .cartao {{ background: white; padding: 20px; border-radius: 12px;
                 box-shadow: 0 2px 8px #0002; max-width: 600px; }}
    </style></head>
    <body><div class="cartao"><h1>{titulo}</h1>{conteudo}</div></body></html>
    """

@app.route("/")
def inicio():
    return pagina("Tua Caneca", "<p>Bem-vindo à loja! <a href='/catalogo'>Ver catálogo →</a></p>")

Repare nas chaves duplas {{ }} no CSS e simples { } nas variáveis — a f-string precisa saber quem é quem!

EX 09

Projeto: O site da Tua Caneca ☕🌐

⭐⭐⭐ desafio

🧭 Requisitos

  2. /catalogo: TABELA HTML dos produtos (<table> com cabeçalho), dados do catalogo.json
  3. /api/produtos: o JSON para os programas
  4. Tudo com a função pagina() do exercício anterior
✅ Saída esperada
terminal
(três rotas, um site de verdade!)
🔑 Ver solução

Só abra depois de tentar!

solucao_ex09.py
import json
from flask import Flask, jsonify

app = Flask(__name__)

def carregar():
    with open("catalogo.json", "r", encoding="utf-8") as arquivo:
        return json.load(arquivo)

def pagina(titulo, conteudo):
    return f"""
    <html><head><title>{titulo}</title>
    <style>
      body {{ font-family: Arial; background: #F5F8FC; margin: 40px; }}
      h1 {{ color: #3776AB; }}
      table {{ border-collapse: collapse; background: white; }}
      td, th {{ border: 1px solid #ccc; padding: 8px 14px; }}
    </style></head>
    <body><h1>{titulo}</h1>{conteudo}</body></html>
    """

@app.route("/")
def inicio():
    return pagina("☕ Tua Caneca",
                  "<p>Personalizados com sublimação.</p>"
                  "<a href='/catalogo'>Catálogo</a> · <a href='/api/produtos'>API</a>")

@app.route("/catalogo")
def catalogo():
    linhas = ""
    for p in carregar():
        linhas = linhas + (f"<tr><td>{p['nome']}</td>"
                           f"<td>R$ {p['preco']:.2f}</td>"
                           f"<td>{p['estoque']}</td></tr>")
    tabela = ("<table><tr><th>Produto</th><th>Preço</th><th>Estoque</th></tr>"
              + linhas + "</table>")
    return pagina("Catálogo", tabela)

@app.route("/api/produtos")
def api_produtos():
    return jsonify(carregar())

app.run(debug=True)
