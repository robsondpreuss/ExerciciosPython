01

class: o molde e os bolos

Conceito

Uma classe é um molde; um objeto é o que sai do molde. O molde "Cachorro" define que todo cachorro tem nome; Rex e Bidu são objetos — cada um com SEU nome.

estrutura.py
class Cachorro:                  # o molde (nome com Maiúscula!)
    def __init__(self, nome):    # executa ao criar o objeto
        self.nome = nome         # guarda o atributo NO objeto

rex = Cachorro("Rex")            # cria um objeto a partir do molde
print(rex.nome)                  # acessa o atributo

E aqui o segredo: você já usa objetos desde sempre! "abc".upper(), lista.append(...), datetime.now().year — strings, listas e datas SÃO objetos, com métodos e atributos. Agora você vai criar os seus.

03

Métodos: o que o objeto sabe fazer

Conceito

Atributos = o que o objeto TEM. Métodos = o que o objeto FAZ. Um método é uma função dentro da classe, sempre com self — e por isso enxerga os atributos do próprio objeto.

Latir e brincar

⭐⭐ médio
🎯 Objetivo

🧭 Passo a passo

class Cachorro:
    def __init__(self, nome):
        self.nome = nome
        self.energia = 100

    def latir(self):
        print(f"{self.nome}: Au au!")

    def brincar(self, horas):
        self.energia = self.energia - horas * 10
        print(f"{self.nome} brincou {horas}h! Energia: {self.energia}")

💡 Repare

solucao_ex07.py
class Cachorro:
    def __init__(self, nome):
        self.nome = nome
        self.energia = 100

    def brincar(self, horas):
        self.energia = self.energia - horas * 10
        print(f"{self.nome} brincou {horas}h! Energia: {self.energia}")

    def esta_cansado(self):
        return self.energia < 30

    def dormir(self):
        self.energia = 100
        print(f"{self.nome} dormiu! Energia: {self.energia}")

rex = Cachorro("Rex")
rex.brincar(8)
print(f"Rex está cansado? {rex.esta_cansado()}")

if rex.esta_cansado():
    rex.dormir()
EX 08

Conta bancária 🏦

⭐⭐⭐ desafio
🎯 Objetivo

O exercício clássico de POO: estado protegido por métodos com regras.

🧭 Passo a passo
  1. Classe ContaBancaria: titular e saldo (padrão 0 — parâmetro padrão da Semana 6!)
  2. depositar(valor): soma e confirma
  3. sacar(valor): só permite se houver saldo (senão avisa)
  4. extrato(): mostra titular e saldo formatado
✅ Exemplo de execução
terminal
Depósito de R$ 100.00 ✔
Saque de R$ 30.00 ✔
Saldo insuficiente!
Ana: R$ 70.00
🚀 Desafio extra
Adicione self.historico = [] e registre cada operação. O extrato() lista tudo!
🔑 Ver solução

Só abra depois de tentar!

solucao_ex08.py
class ContaBancaria:
    def __init__(self, titular, saldo=0):
        self.titular = titular
        self.saldo = saldo

    def depositar(self, valor):
        self.saldo = self.saldo + valor
        print(f"Depósito de R$ {valor:.2f} ✔")

    def sacar(self, valor):
        if valor > self.saldo:
            print("Saldo insuficiente!")
        else:
            self.saldo = self.saldo - valor
            print(f"Saque de R$ {valor:.2f} ✔")

    def extrato(self):
        print(f"{self.titular}: R$ {self.saldo:.2f}")

conta = ContaBancaria("Ana")
conta.depositar(100)
conta.sacar(30)
conta.sacar(500)
conta.extrato()

Sente a elegância: NINGUÉM mexe no saldo diretamente — toda mudança passa pelos métodos, que aplicam as regras. Isso é encapsulamento, um dos pilares da POO.

__str__: o print bonito

Conceito

O que acontece se você der print(rex)? Algo feio: <__main__.Cachorro object at 0x000001E...>. O método especial __str__ resolve: ele define COMO o objeto vira texto.

EX 09

De feio para bonito

⭐⭐ médio
🎯 Objetivo

Implementar o __str__.

🧭 Passo a passo
  1. Primeiro dê print(rex) SEM __str__ e veja o endereço feio
  2. Adicione o método e imprima de novo:
ex09_str.py
class Cachorro:
    def __init__(self, nome, idade):
        self.nome = nome
        self.idade = idade

    def __str__(self):
        return f"🐶 {self.nome} ({self.idade} anos)"

rex = Cachorro("Rex", 3)

💡 Regra do __str__
Ele deve RETORNAR uma string (não usar print dentro!). Sempre que o objeto precisar virar texto — print, f-string — o Python chama seu __str__ automaticamente.

Projeto: classe Produto ☕

⭐⭐⭐ desafio
🎯 Objetivo

O Produto da Tua Caneca vira uma classe de verdade — peça-chave do projeto final!

🧭 Requisitos
  1. Atributos: nome, preco, estoque
  2. vender(qtd): valida o estoque; se ok, dá baixa e retorna True; senão avisa e retorna False
  3. repor(qtd): aumenta o estoque
  4. __str__: "caneca branca — R$ 25.00 (10 un.)"
✅ Exemplo de execução
terminal
caneca branca — R$ 25.00 (10 un.)
Vendido: 3x caneca branca
caneca branca — R$ 25.00 (7 un.)
Estoque insuficiente!
🔑 Ver solução

Só abra depois de tentar!

solucao_ex12.py
class Produto:
    def __init__(self, nome, preco, estoque):
        self.nome = nome
        self.preco = preco
        self.estoque = estoque

    def vender(self, qtd):
        if qtd <= 0 or qtd > self.estoque:
            print("Estoque insuficiente!")
            return False
        self.estoque = self.estoque - qtd
        print(f"Vendido: {qtd}x {self.nome}")
        return True

    def repor(self, qtd):
        self.estoque = self.estoque + qtd
        print(f"Reposição: +{qtd} {self.nome}")

    def __str__(self):
        return f"{self.nome} — R$ {self.preco:.2f} ({self.estoque} un.)"

caneca = Produto("caneca branca", 25.0, 10)
print(caneca)
caneca.vender(3)
print(caneca)
caneca.vender(50)

Projeto: classe Aluno 🎓

⭐⭐⭐ desafio
🎯 Objetivo

Um Aluno que guarda as próprias notas e sabe se avaliar.

🧭 Requisitos
  1. Atributos: nome e self.notas = [] (nasce vazia!)
  2. adicionar_nota(nota): append na lista interna
  3. media(): retorna a média (cuidado com lista vazia → retorne 0)
  4. situacao(): "Aprovado" se média ≥ 7, senão "Recuperação"
✅ Exemplo de execução
terminal
Ana: média 8.0 — Aprovado
Bruno: média 5.5 — Recuperação
🔑 Ver solução

Só abra depois de tentar!

solucao_ex13.py
class Aluno:
    def __init__(self, nome):
        self.nome = nome
        self.notas = []

    def adicionar_nota(self, nota):
        self.notas.append(nota)

    def media(self):
        if len(self.notas) == 0:
            return 0
        return sum(self.notas) / len(self.notas)

    def situacao(self):
        if self.media() >= 7:
            return "Aprovado"
        return "Recuperação"

ana = Aluno("Ana")
ana.adicionar_nota(8)
ana.adicionar_nota(8)

bruno = Aluno("Bruno")
bruno.adicionar_nota(6)
bruno.adicionar_nota(5)

for aluno in [ana, bruno]:
    print(f"{aluno.nome}: média {aluno.media():.1f} — {aluno.situacao()}")

Repare: situacao() chama self.media() — métodos podem usar outros métodos do próprio objeto!

EX 14

Projeto bônus: A batalha ⚔️

⭐⭐⭐ desafio
🎯 Objetivo

Um mini-RPG: dois objetos da mesma classe duelando (sem código pronto!).

🧭 Roteiro
  1. Classe Personagem: nome, vida (padrão 100), força (padrão 15)
  2. atacar(alvo): dano aleatório de 5 até a força, descontado da vida DO ALVO (um objeto mexendo em outro!)
  3. esta_vivo(): retorna self.vida > 0
  4. Loop de batalha: herói e dragão se atacam alternadamente até alguém cair
✅ Exemplo (varia!)
terminal
Herói causou 12 em Dragão (vida: 108)
Dragão causou 18 em Herói (vida: 82)
(...)
🏆 O herói venceu!
💡 O pulo do gato
No atacar(self, alvo), o self é quem bate e o alvo é outro OBJETO que apanha: alvo.vida -= dano. Objetos interagindo entre si — é assim que sistemas grandes funcionam!
🔑 Ver solução

Só abra depois de tentar!

solucao_ex14.py
import random

class Personagem:
    def __init__(self, nome, vida=100, forca=15):
        self.nome = nome
        self.vida = vida
        self.forca = forca

    def atacar(self, alvo):
        dano = random.randint(5, self.forca)
        alvo.vida = alvo.vida - dano
        print(f"{self.nome} causou {dano} em {alvo.nome} (vida: {alvo.vida})")

    def esta_vivo(self):
        return self.vida > 0

heroi = Personagem("Herói")
dragao = Personagem("Dragão", vida=120, forca=20)

while heroi.esta_vivo() and dragao.esta_vivo():
    heroi.atacar(dragao)
    if dragao.esta_vivo():
        dragao.atacar(heroi)

if heroi.esta_vivo():
    print("🏆 O herói venceu!")
else:
    print("💀 O dragão venceu!")
