01

O DataFrame: sua tabela superpoderosa

Conceito

Instale com pip install pandas openpyxl. O DataFrame é a tabela do pandas: linhas e colunas com nome — a evolução natural da "lista de dicionários" que você usa desde a Semana 5, agora com centenas de operações prontas. A convenção mundial é importar como import pandas as pd.

EX 01

Primeiro DataFrame 🐼

⭐⭐ médio
🎯 Objetivo

Criar uma tabela a partir de um dicionário de listas.

🧭 Passo a passo
  1. Digite e execute — repare no formato: cada CHAVE vira uma coluna:
ex01_dataframe.py
import pandas as pd

dados = {
    "produto": ["caneca branca", "caneca preta", "azulejo"],
    "qtd": [3, 12, 2],
    "total": [75.0, 270.0, 80.0]
}

df = pd.DataFrame(dados)
print(df)
✅ Saída esperada
terminal
         produto  qtd  total
0  caneca branca    3   75.0
1   caneca preta   12  270.0
2        azulejo    2   80.0
💡 Dica
A coluna de números à esquerda (0, 1, 2) é o ÍNDICE — o pandas numera as linhas sozinho, como os índices de lista da Semana 4. E "df" é a abreviação universal de DataFrame.

EX 12

Projeto: Análise completa Tua Caneca 📊

⭐⭐⭐ desafio
🎯 Objetivo

Refazer a análise da Central (Semana 16) inteirinha em pandas — e sentir a diferença.

🧭 Requisitos
  1. Leia o vendas.csv
  2. Calcule: faturamento, unidades, ticket médio, campeão (groupby + idxmax)
  3. Crie a coluna "unitario" e identifique a venda com MENOR preço unitário (o maior desconto!)
  4. Exporte o resumo por produto para resumo_pandas.xlsx
✅ Exemplo de execução
terminal
Faturamento: R$ 702.50
Unidades: 27
Ticket médio: R$ 117.08
Campeão: caneca preta
Maior desconto: caneca preta a R$ 22.50/un.
resumo_pandas.xlsx gerado ✔
🔑 Ver solução

Só abra depois de tentar!

solucao_ex12.py
import pandas as pd

df = pd.read_csv("vendas.csv")

print(f"Faturamento: R$ {df['total'].sum():.2f}")
print(f"Unidades: {df['qtd'].sum()}")
print(f"Ticket médio: R$ {df['total'].mean():.2f}")
print(f"Campeão: {df.groupby('produto')['qtd'].sum().idxmax()}")

df["unitario"] = df["total"] / df["qtd"]
barata = df.sort_values("unitario").head(1)
produto = barata["produto"].values[0]
unitario = barata["unitario"].values[0]
print(f"Maior desconto: {produto} a R$ {unitario:.2f}/un.")

resumo = df.groupby("produto")["total"].sum().reset_index()
resumo.to_excel("resumo_pandas.xlsx", index=False)
print("resumo_pandas.xlsx gerado ✔")

Compare com a função analisar() da Semana 16: o conhecimento dos loops fez você ENTENDER; o pandas faz você VOAR.

EX 13

Projeto: Boletim turbinado 🎓

⭐⭐⭐ desafio
🎯 Objetivo

A análise da turma com médias por aluno via groupby.

🧭 Requisitos
  1. Monte (ou leia de CSV) notas com colunas aluno e nota — vários registros por aluno
  2. Média por aluno: groupby("aluno")["nota"].mean()
  3. Filtre os aprovados (média ≥ 7) e exporte boletim_pandas.xlsx
✅ Exemplo de execução
terminal
aluno
Ana      8.25
Bruno    5.50
Carla    9.50
Aprovados: 2
🔑 Ver solução

Só abra depois de tentar!

solucao_ex13.py
import pandas as pd

notas = pd.DataFrame({
    "aluno": ["Ana", "Ana", "Bruno", "Bruno", "Carla", "Carla"],
    "nota": [8.0, 8.5, 6.0, 5.0, 9.5, 9.5]
})

medias = notas.groupby("aluno")["nota"].mean()
print(medias)

aprovados = medias[medias >= 7]
print(f"Aprovados: {len(aprovados)}")

medias.reset_index().to_excel("boletim_pandas.xlsx", index=False)
