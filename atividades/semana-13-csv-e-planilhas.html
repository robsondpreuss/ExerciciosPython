Lendo CSV do jeito profissional

Conceito

Na Semana 7 você inventou o "CSV caseiro" com split(";"). O Python tem um módulo oficial que trata os casos difíceis (vírgulas dentro de textos, aspas...): o csv. Primeiro, crie o arquivo de testes vendas.csv no Bloco de Notas (ou via código):

vendas.csv
produto,qtd,total
caneca branca,3,75.00
caneca preta,2,55.00
azulejo,1,40.00
EX 01

csv.reader: cada linha vira lista

⭐⭐ médio
🎯 Objetivo

Ler um CSV com o módulo oficial.

🧭 Passo a passo
  1. Com o vendas.csv na mesma pasta, execute:
ex01_reader.py
import csv

with open("vendas.csv", "r", encoding="utf-8") as arquivo:
    leitor = csv.reader(arquivo)
    for linha in leitor:
        print(linha)
✅ Saída esperada
terminal
['produto', 'qtd', 'total']
['caneca branca', '3', '75.00']
['caneca preta', '2', '55.00']
['azulejo', '1', '40.00']
💡 Duas observações
(1) TUDO chega como texto — converta com int/float quando precisar. (2) A primeira linha é o cabeçalho: pule-a com next(leitor) antes do for. E se seu Excel salvar com ponto e vírgula, use csv.reader(arquivo, delimiter=";").
EX 02

DictReader: cada linha vira dicionário 🤩

⭐⭐ médio
🎯 Objetivo

A forma mais elegante de ler CSV — direto para dicionários.

🧭 Passo a passo
  1. Troque o reader por DictReader e acesse por NOME de coluna:
ex02_dictreader.py
import csv

with open("vendas.csv", "r", encoding="utf-8") as arquivo:
    leitor = csv.DictReader(arquivo)
    for linha in leitor:
        print(f"{linha['produto']}: {linha['qtd']} un. — R$ {linha['total']}")
✅ Saída esperada
terminal
caneca branca: 3 un. — R$ 75.00
caneca preta: 2 un. — R$ 55.00
azulejo: 1 un. — R$ 40.00
💡 Olha a Semana 5 aí
O DictReader usa o cabeçalho como chaves e entrega... uma lista de dicionários — a "tabela" que você já domina! Nada de contar posição de coluna.
02

Gravando CSV

Conceito

Para escrever, a dupla csv.writer + writerow — com um detalhe OBRIGATÓRIO no Windows: newline="" no open (sem ele, o arquivo sai com linhas em branco entre os dados!).

EX 03

Primeiro CSV gerado

⭐⭐ médio
🎯 Objetivo

Gravar um CSV linha a linha.

🧭 Passo a passo
  1. Digite, execute e abra o resultado no Excel ou Bloco de Notas:
ex03_writer.py
import csv

with open("clientes.csv", "w", newline="", encoding="utf-8") as arquivo:
    escritor = csv.writer(arquivo)
    escritor.writerow(["nome", "cidade"])
    escritor.writerow(["Ana", "Porto Alegre"])
    escritor.writerow(["Bruno", "Caxias do Sul"])

print("clientes.csv gerado ✔")
✅ Saída esperada
terminal
clientes.csv gerado ✔
💡 O bug das linhas em branco
Esqueceu o newline=""? No Windows, cada linha de dados ganha uma linha vazia embaixo. É a pegadinha número 1 do módulo csv — agora você está vacinado!
EX 04

DictWriter: gravando dicionários

⭐⭐⭐ desafio
🎯 Objetivo

O par do DictReader: gravar a partir de dicionários.

🧭 Passo a passo
  1. Defina campos = ["nome", "nota"]
  2. Crie o DictWriter com fieldnames=campos
  3. Chame writeheader() (grava o cabeçalho) e depois writerow com dicionários
ex04_dictwriter.py
import csv

campos = ["nome", "nota"]
alunos = [
    {"nome": "Ana", "nota": 8.5},
    {"nome": "Bruno", "nota": 6.0},
    {"nome": "Carla", "nota": 9.5}
]

with open("notas.csv", "w", newline="", encoding="utf-8") as arquivo:
    escritor = csv.DictWriter(arquivo, fieldnames=campos)
    escritor.writeheader()
    for aluno in alunos:
        escritor.writerow(aluno)

print("notas.csv gerado ✔")
✅ Saída esperada
terminal
notas.csv gerado ✔
EX 05

Filtro CSV → CSV

⭐⭐⭐ desafio
🎯 Objetivo

O pipeline clássico de dados: ler, filtrar, gravar.

🧭 Passo a passo
  1. Leia o notas.csv com DictReader
  2. Filtre quem tem nota ≥ 7 (lembre: converta com float(linha["nota"])!)
  3. Grave os aprovados em aprovados.csv com DictWriter
✅ Exemplo de execução
terminal
2 aprovados gravados em aprovados.csv ✔
🔑 Ver solução

Só abra depois de tentar!

solucao_ex05.py
import csv

aprovados = []

with open("notas.csv", "r", encoding="utf-8") as arquivo:
    leitor = csv.DictReader(arquivo)
    for linha in leitor:
        if float(linha["nota"]) >= 7:
            aprovados.append(linha)

with open("aprovados.csv", "w", newline="", encoding="utf-8") as arquivo:
    escritor = csv.DictWriter(arquivo, fieldnames=["nome", "nota"])
    escritor.writeheader()
    for aluno in aprovados:
        escritor.writerow(aluno)

print(f"{len(aprovados)} aprovados gravados em aprovados.csv ✔")

Ler → transformar → gravar: você acabou de fazer um mini-ETL, o trabalho diário de quem mexe com dados!

openpyxl: o Excel de verdade

Conceito

CSV é texto puro — sem abas, fórmulas ou formatação. Para .xlsx de verdade, a biblioteca openpyxl. Instale no terminal: pip install openpyxl (Semana 9!). O modelo mental: Workbook = o arquivo · aba (worksheet) = cada planilha · célula = aba["A1"].

EX 06

Primeira planilha .xlsx

⭐⭐ médio
🎯 Objetivo

Criar um Excel do zero com Python.

🧭 Passo a passo
  1. Com o openpyxl instalado, execute:
  2. Depois ABRA o vendas.xlsx no Excel e admire 😄
ex06_workbook.py
from openpyxl import Workbook

planilha = Workbook()
aba = planilha.active
aba.title = "Vendas"

Números vão SEM aspas (aba["B2"] = 75.0) — assim o Excel os trata como números de verdade, somáveis. Com aspas virariam texto!
EX 07

Lendo uma planilha

⭐⭐ médio
🎯 Objetivo

Abrir um .xlsx existente e percorrer os dados.

🧭 Passo a passo

from openpyxl import load_workbook

planilha = load_workbook("vendas.xlsx")
aba = planilha.active

print(aba["A1"].value)

for linha in aba.iter_rows(min_row=2, values_only=True):
    print(linha)

💡 Dica

EX 09

Negrito e fórmula =SUM 🧮

⭐⭐⭐ desafio
🎯 Objetivo

Formatar o cabeçalho e deixar o EXCEL calcular o total.

🧭 Passo a passo
  1. Importe from openpyxl.styles import Font
  2. Negrito no cabeçalho: for celula in aba[1]: celula.font = Font(bold=True)
  3. Fórmula como texto: aba["C5"] = "=SUM(C2:C4)" — o Excel calcula ao abrir!
✅ Saída esperada
terminal
tabela.xlsx atualizada ✔ (abra e veja o total calculado!)
💡 Por que fórmula e não soma em Python?
Você PODE somar em Python e gravar o número. Mas a fórmula deixa a planilha VIVA: se alguém editar um valor no Excel, o total se atualiza. Escolha conforme o uso!
🔑 Ver solução

Só abra depois de tentar!

solucao_ex09.py
from openpyxl import Workbook
from openpyxl.styles import Font

dados = [
    ("caneca branca", 3, 75.0),
    ("caneca preta", 2, 55.0),
    ("azulejo", 1, 40.0)
]

planilha = Workbook()
aba = planilha.active

aba.append(["Produto", "Qtd", "Total"])
for celula in aba[1]:
    celula.font = Font(bold=True)

for linha in dados:
    aba.append(linha)

aba["B5"] = "TOTAL:"
aba["C5"] = "=SUM(C2:C4)"
aba["B5"].font = Font(bold=True)

planilha.save("tabela.xlsx")
print("tabela.xlsx atualizada ✔")

CSV → Excel: a conversão mágica

Conceito

O combo das duas metades da semana: ler um CSV cru e entregar um .xlsx formatado. É um dos scripts mais pedidos em qualquer escritório!

EX 10

O conversor

⭐⭐⭐ desafio
🎯 Objetivo

Transformar vendas.csv numa planilha Excel com números de verdade.

🧭 Passo a passo
  1. Leia o vendas.csv com csv.reader
  2. O cabeçalho vai direto com append; nas linhas de dados, CONVERTA: qtd → int, total → float
  3. Salve como vendas_convertidas.xlsx
✅ Exemplo de execução
terminal
Convertido: vendas.csv → vendas_convertidas.xlsx ✔
🔑 Ver solução

Só abra depois de tentar!

solucao_ex10.py
import csv
from openpyxl import Workbook

planilha = Workbook()
aba = planilha.active

with open("vendas.csv", "r", encoding="utf-8") as arquivo:
    leitor = csv.reader(arquivo)
    cabecalho = next(leitor)
    aba.append(cabecalho)
    for linha in leitor:
        produto = linha[0]
        qtd = int(linha[1])
        total = float(linha[2])
        aba.append([produto, qtd, total])

planilha.save("vendas_convertidas.xlsx")
print("Convertido: vendas.csv → vendas_convertidas.xlsx ✔")

Sem a conversão int/float, os números chegariam como TEXTO no Excel (alinhados à esquerda, não somáveis). Esse detalhe é o que faz seu conversor ser melhor que muito script por aí!

EX 11

Projeto: Relatório de vendas em Excel ☕📊

⭐⭐⭐ desafio
🎯 Objetivo

O relatório da Tua Caneca sai do terminal e vira uma planilha apresentável.

🧭 Requisitos
  1. Monte os dados de vendas (lista de tuplas ou leia do seu vendas.csv)
  2. Planilha com: cabeçalho em negrito, dados, linha de TOTAL com =SUM
  3. Bônus: uma segunda aba "Resumo" com planilha.create_sheet("Resumo") contendo o campeão de vendas
✅ Exemplo de execução
terminal
relatorio_vendas.xlsx gerado ✔
🔑 Ver solução

Só abra depois de tentar!

solucao_ex11.py
from openpyxl import Workbook
from openpyxl.styles import Font

vendas = [
    ("caneca branca", 3, 75.0),
    ("caneca preta", 12, 270.0),
    ("azulejo", 2, 80.0)
]

planilha = Workbook()
aba = planilha.active
aba.title = "Vendas"

aba.append(["Produto", "Qtd", "Total (R$)"])
for celula in aba[1]:
    celula.font = Font(bold=True)

for venda in vendas:
    aba.append(venda)

linha_total = len(vendas) + 2
aba[f"B{linha_total}"] = "TOTAL:"
aba[f"C{linha_total}"] = f"=SUM(C2:C{len(vendas) + 1})"

resumo = planilha.create_sheet("Resumo")
campeao = ""
maior = 0
for nome, qtd, total in vendas:
    if qtd > maior:
        maior = qtd
        campeao = nome
resumo["A1"] = "Campeão de vendas"
resumo["B1"] = campeao

planilha.save("relatorio_vendas.xlsx")
print("relatorio_vendas.xlsx gerado ✔")
EX 12

Projeto: Boletim CSV → Excel 🎓

⭐⭐⭐ desafio
🎯 Objetivo

Pipeline completo: notas em CSV viram boletim Excel com situação calculada.

🧭 Requisitos
  1. Leia o notas.csv com DictReader
  2. Para cada aluno, calcule a situação (média ≥ 7 → Aprovado)
  3. Grave boletim.xlsx com 3 colunas: Nome, Nota, Situação (cabeçalho em negrito)
✅ Exemplo de execução
terminal
boletim.xlsx gerado: 3 alunos ✔
🔑 Ver solução

Só abra depois de tentar!

solucao_ex12.py
import csv
from openpyxl import Workbook
from openpyxl.styles import Font

planilha = Workbook()
aba = planilha.active
aba.append(["Nome", "Nota", "Situação"])
for celula in aba[1]:
    celula.font = Font(bold=True)

contador = 0
with open("notas.csv", "r", encoding="utf-8") as arquivo:
    leitor = csv.DictReader(arquivo)
    for linha in leitor:
        nota = float(linha["nota"])
        if nota >= 7:
            situacao = "Aprovado"
        else:
            situacao = "Recuperação"
        aba.append([linha["nome"], nota, situacao])
        contador = contador + 1

planilha.save("boletim.xlsx")
print(f"boletim.xlsx gerado: {contador} alunos ✔")
EX 13

Projeto bônus: JSON → Excel

⭐⭐⭐ desafio
🎯 Objetivo

Fechar o ciclo dos formatos: o catálogo da Semana 11 vira planilha (sem código pronto!).

🧭 Roteiro
  1. Carregue o catalogo.json (ou crie um com 3 produtos)
  2. Gere catalogo.xlsx com Nome, Preço e Estoque
  3. Acrescente uma coluna calculada: "Valor em estoque" = preço × estoque
  4. Reflita: você agora converte entre JSON ↔ CSV ↔ Excel — é oficialmente uma pessoa que domina formatos de dados!
✅ Exemplo de execução
terminal
catalogo.xlsx gerado ✔
🔑 Ver solução

Só abra depois de tentar!

solucao_ex13.py
import json
from openpyxl import Workbook

with open("catalogo.json", "r", encoding="utf-8") as arquivo:
    produtos = json.load(arquivo)

planilha = Workbook()
aba = planilha.active
aba.append(["Nome", "Preço", "Estoque", "Valor em estoque"])

for p in produtos:
    valor = p["preco"] * p["estoque"]
    aba.append([p["nome"], p["preco"], p["estoque"], valor])

planilha.save("catalogo.xlsx")
print("catalogo.xlsx gerado ✔")
