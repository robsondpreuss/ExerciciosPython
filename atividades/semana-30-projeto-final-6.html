EX 02

Caça aos bugs do módulo profissional 🐛

⭐⭐⭐ desafio
🎯 Objetivo

Os erros mais comuns de API REST + JWT + MariaDB.

🧭 Passo a passo
  1. Este endpoint protegido deveria criar um produto — ache os 4 bugs:
bugs.py
@app.route("/api/produtos")
def criar(usuario_logado):
    dados = request.get_json()
    cursor.execute(
        "INSERT INTO produtos (nome, preco) VALUES (?, ?)",
        (dados["nome"], dados["preco"]))
    return jsonify({"ok": True})
🔑 Ver solução

Só abra depois de tentar!

Os 4 bugs: (1) a rota não declara o método — para criar, precisa methods=["POST"] (sem isso, só aceita GET). (2) falta o @token_required em cima da rota (ela recebe usuario_logado, mas ninguém o fornece sem o decorator). (3) placeholders ? são do SQLite — no MariaDB/PyMySQL é %s! (4) falta o commit() (e idealmente o status 201 no retorno).

corrigido.py
@app.route("/api/produtos", methods=["POST"])
@token_required
def criar(usuario_logado):
    dados = request.get_json()
    con = conectar(); cur = con.cursor()
    cur.execute(
        "INSERT INTO produtos (nome, preco, estoque) VALUES (%s, %s, %s)",
        (dados["nome"], dados["preco"], dados["estoque"]))
    con.commit()
    novo_id = cur.lastrowid
    con.close()
    return jsonify({"id": novo_id, "ok": True}), 201

Esses quatro — método faltando, decorator esquecido, ? no lugar de %s e commit ausente — são os tropeços clássicos do módulo. Reconhecê-los de cara economiza horas!

🔑 Ver solução

Só abra depois de tentar!

backend/auth.py
import os, jwt
from functools import wraps
from flask import jsonify, request

SEGREDO = os.environ.get("JWT_SECRET", "troque-este-segredo")

def token_required(f):
    @wraps(f)
    def wrapper(*args, **kwargs):
        cab = request.headers.get("Authorization", "")
        if not cab.startswith("Bearer "):
            return jsonify({"erro": "token ausente"}), 401
        try:
            dados = jwt.decode(cab.split(" ")[1], SEGREDO, algorithms=["HS256"])
        except jwt.ExpiredSignatureError:
            return jsonify({"erro": "token expirado"}), 401
        except jwt.InvalidTokenError:
            return jsonify({"erro": "token invalido"}), 401
        return f(usuario_logado=dados["usuario"], *args, **kwargs)
    return wrapper

Etapa 5: vendas e relatório 📊

⭐⭐⭐ desafio
🎯 Objetivo

Fechar o sistema com o fluxo de vendas e um relatório.

🧭 Passo a passo
  1. POST /api/vendas (protegido): recebe produto_id e qtd, confere estoque, dá baixa (UPDATE) e registra (INSERT)
  2. GET /api/relatorio: um GROUP BY (Semana 22) com o total vendido por produto, em JSON
  3. No frontend, uma área que lista o relatório consumindo esse endpoint
  4. O sistema agora cadastra, vende e analisa — um ciclo de negócio completo
✅ Exemplo
terminal
POST /api/vendas {"produto_id": 1, "qtd": 3} -> 201
GET /api/relatorio -> [{"produto": "caneca branca", "total_vendido": 3}, ...]
🔑 Ver solução

Só abra depois de tentar!

backend/api.py (trecho)
@app.route("/api/vendas", methods=["POST"])
@token_required
def vender(usuario_logado):
    d = request.get_json()
    con = conectar(); cur = con.cursor()
    cur.execute("SELECT preco, estoque FROM produtos WHERE id=%s", (d["produto_id"],))
    r = cur.fetchone()
    if r is None:
        con.close(); return jsonify({"erro": "produto inexistente"}), 404
    if r[1] < d["qtd"]:
        con.close(); return jsonify({"erro": "estoque insuficiente"}), 400
    total = float(r[0]) * d["qtd"]
    cur.execute("UPDATE produtos SET estoque = estoque - %s WHERE id=%s",
                (d["qtd"], d["produto_id"]))
    cur.execute("INSERT INTO vendas (produto_id, qtd, total) VALUES (%s, %s, %s)",
                (d["produto_id"], d["qtd"], total))
    con.commit(); con.close()
    return jsonify({"ok": True, "total": total}), 201

@app.route("/api/relatorio")
def relatorio():
    con = conectar(); cur = con.cursor()
    cur.execute("""SELECT p.nome, SUM(v.qtd) AS total
                   FROM vendas v JOIN produtos p ON p.id = v.produto_id
                   GROUP BY p.nome ORDER BY total DESC""")
    dados = [{"produto": n, "total_vendido": int(t)} for n, t in cur.fetchall()]
    con.close()
    return jsonify(dados)

Olha o JOIN aparecendo no relatório — ligando vendas e produtos pelo id! É um passo além do GROUP BY simples (Semana 22), e um ótimo tema para você se aprofundar a seguir.
