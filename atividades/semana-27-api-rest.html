EX 01

Montando o laboratório 🧪

⭐ básico
🎯 Objetivo

Criar uma pasta de testes com arquivos falsos — seu campo de treino seguro.

🧭 Passo a passo
  1. Execute este script: ele cria a pasta laboratorio com 7 arquivos de mentira
ex01_setup.py
import os

os.makedirs("laboratorio", exist_ok=True)

nomes = ["foto1.jpg", "foto2.png", "relatorio.pdf", "notas.txt",
         "planilha.xlsx", "musica.mp3", "rascunho.txt"]

for nome in nomes:
    caminho = os.path.join("laboratorio", nome)
    with open(caminho, "w") as arquivo:
        arquivo.write("arquivo de teste\n")

print("Laboratório montado com", len(nomes), "arquivos ✔")

EX 03

Censo por extensão 📊

⭐⭐ médio
🎯 Objetivo

Filtrar e contar arquivos por tipo — o dict contador ataca novamente!

🧭 Passo a passo
  1. Liste só os .txt usando if nome.endswith(".txt")
  2. Depois conte TODOS os tipos: a extensão é nome.split(".")[-1] — use o padrão contagem.get(ext, 0) + 1
✅ Saída esperada
terminal
Arquivos .txt: ['notas.txt', 'rascunho.txt']
Censo: {'jpg': 1, 'png': 1, 'pdf': 1, 'txt': 2, 'xlsx': 1, 'mp3': 1}
🔑 Ver solução

Só abra depois de tentar!

solucao_ex03.py
import os

arquivos = os.listdir("laboratorio")

txts = []
for nome in arquivos:
    if nome.endswith(".txt"):
        txts.append(nome)
print(f"Arquivos .txt: {txts}")

contagem = {}
for nome in arquivos:
    ext = nome.split(".")[-1]
    contagem[ext] = contagem.get(ext, 0) + 1
print(f"Censo: {contagem}")

Criando pastas e renomeando em lote

Conceito

Criar: os.makedirs(caminho, exist_ok=True) (o exist_ok evita erro se já existir). Conferir: os.path.exists(caminho). Renomear: os.rename(antigo, novo) — que em lote, dentro de um for, vira uma máquina de produtividade.

EX 05

Renomeando em lote 🏷️

⭐⭐⭐ desafio
🎯 Objetivo

Adicionar um prefixo a todos os .txt — o clássico pedido de escritório.

🧭 Passo a passo
  1. Percorra o laboratório filtrando os .txt
  2. Para cada um, monte o nome novo: "2026_" + nome
  3. Renomeie com os.rename(caminho_antigo, caminho_novo) — SEMPRE com os caminhos completos via join!
  4. Liste a pasta para conferir
✅ Saída esperada
terminal
notas.txt → 2026_notas.txt
rascunho.txt → 2026_rascunho.txt
💡 Cuidado clássico
O rename precisa do CAMINHO completo dos dois lados. Só o nome do arquivo funciona apenas se o script estiver rodando dentro da própria pasta — e aí qualquer descuido renomeia a coisa errada!
🔑 Ver solução

Só abra depois de tentar!

solucao_ex05.py
import os

for nome in os.listdir("laboratorio"):
    if nome.endswith(".txt"):
        antigo = os.path.join("laboratorio", nome)
        novo = os.path.join("laboratorio", "2026_" + nome)
        os.rename(antigo, novo)
        print(f"{nome} → 2026_{nome}")
03

shutil: copiar e mover

Conceito

O os organiza; o shutil transporta: shutil.copy(origem, destino) copia (o original fica) e shutil.move(origem, destino) move (o original vai embora). O destino pode ser uma PASTA — o arquivo entra nela com o mesmo nome.

EX 07

Movendo por extensão

⭐⭐⭐ desafio
🎯 Objetivo

O coração do organizador: cada tipo para sua pasta.

🧭 Passo a passo
  1. Percorra os arquivos da RAIZ do laboratório (pule as pastas! use os.path.isfile ou confira se tem ponto no nome)
  2. jpg/png → Imagens · pdf/txt/xlsx → Documentos · resto → Outros
  3. Mova com shutil.move e relate cada movimento
✅ Exemplo de execução
terminal
foto1.jpg → Imagens
foto2.png → Imagens
2026_notas.txt → Documentos
(...)
🔑 Ver solução

Só abra depois de tentar!

solucao_ex07.py
import os
import shutil

LAB = "laboratorio"

for nome in os.listdir(LAB):
    caminho = os.path.join(LAB, nome)
    if not os.path.isfile(caminho):
        continue   # pula as pastas!

    if nome.endswith(".jpg") or nome.endswith(".png"):
        destino = "Imagens"
    elif nome.endswith(".pdf") or nome.endswith(".txt") or nome.endswith(".xlsx"):
        destino = "Documentos"
    else:
        destino = "Outros"

    shutil.move(caminho, os.path.join(LAB, destino))
    print(f"{nome} → {destino}")

O continue da Semana 3 salvando o dia: pastas não devem ser movidas para dentro de pastas! E repare que o os.path.isfile distingue arquivo de pasta.

EX 08

Relatório de tamanhos

⭐⭐ médio
🎯 Objetivo

Medir cada arquivo da pasta Documentos.

🧭 Passo a passo
  1. Percorra a pasta com listdir
  2. Para cada arquivo: os.path.getsize(caminho) e converta para KB
  3. Exiba alinhado e some o total
✅ Exemplo (tamanhos variam)
terminal
relatorio.pdf — 0.02 KB
2026_notas.txt — 0.02 KB
(...)

🔑 Ver solução

Só abra depois de tentar!

solucao_ex08.py
import os

pasta = os.path.join("laboratorio", "Documentos")
total = 0

for nome in os.listdir(pasta):
    caminho = os.path.join(pasta, nome)
    tamanho_kb = os.path.getsize(caminho) / 1024
    total = total + tamanho_kb
    print(f"{nome} — {tamanho_kb:.2f} KB")

print(f"TOTAL: {total:.2f} KB")
05

Segurança: o dry run

Conceito

A prática que separa o automatizador confiável do destruidor de pastas: o dry run (ensaio). O script primeiro SÓ MOSTRA o que faria; a ação real só roda depois de uma confirmação explícita. Mover arquivo errado dá trabalho; em lote, dá MUITO trabalho.

EX 09

Ensaiando antes de mover 🛡️

⭐⭐⭐ desafio
🎯 Objetivo

Adicionar modo simulação ao organizador.

🧭 Passo a passo
  1. Refaça o Exercício 7 em DUAS passadas:
  2. Passada 1: só imprime "MOVERIA: x → y" (nenhum move!)
  3. Pergunte: "Confirmar? (sim/não)" — só execute os moves de verdade no "sim"
  4. Dica de estrutura: guarde os pares (origem, destino) numa lista na passada 1
✅ Exemplo de execução
terminal
MOVERIA: foto1.jpg → Imagens
MOVERIA: musica.mp3 → Outros
Confirmar? (sim/não): sim
2 arquivos movidos ✔
🔑 Ver solução

Só abra depois de tentar!

solucao_ex09.py
import os
import shutil

LAB = "laboratorio"
planos = []

for nome in os.listdir(LAB):
    caminho = os.path.join(LAB, nome)
    if not os.path.isfile(caminho):
        continue
    if nome.endswith(".jpg") or nome.endswith(".png"):
        destino = "Imagens"
    else:
        destino = "Outros"
    planos.append((caminho, os.path.join(LAB, destino)))
    print(f"MOVERIA: {nome} → {destino}")

if len(planos) == 0:
    print("Nada a mover.")
else:
    resposta = input("Confirmar? (sim/não): ")
    if resposta == "sim":
        for origem, destino in planos:
            shutil.move(origem, destino)
        print(f"{len(planos)} arquivos movidos ✔")
    else:
        print("Operação cancelada — nada foi alterado.")

Repare na lista de TUPLAS (Semana 5!) guardando os planos e no desempacotamento no for final. Esse padrão "planejar → confirmar → executar" vale para QUALQUER automação perigosa.

EX 10

Projeto: Organizador de Downloads 🗂️

⭐⭐⭐ desafio
🎯 Objetivo

O organizador definitivo, com dicionário de regras e dry run.

🧭 Requisitos
  1. Regras num dicionário: {"Imagens": [".jpg", ".png", ".gif"], "Documentos": [".pdf", ".docx", ".txt", ".xlsx"], "Musicas": [".mp3"]} — extensão fora das regras vai para "Outros"
  2. Crie as pastas necessárias (makedirs exist_ok)
  3. Dry run completo + confirmação + execução
  4. TREINE NO LABORATÓRIO! Só aponte para a pasta Downloads real quando estiver 100% confiante
✅ Exemplo de execução
terminal
MOVERIA: foto_ferias.jpg → Imagens
MOVERIA: boleto.pdf → Documentos
Confirmar? (sim/não): sim
2 arquivos organizados ✔
🔑 Ver solução

Só abra depois de tentar!

solucao_ex10.py
import os
import shutil

PASTA = "laboratorio"   # troque para sua pasta real SÓ quando dominar!

REGRAS = {
    "Imagens": [".jpg", ".png", ".gif"],
    "Documentos": [".pdf", ".docx", ".txt", ".xlsx"],
    "Musicas": [".mp3"]
}

def descobrir_destino(nome):
    for pasta, extensoes in REGRAS.items():
        for ext in extensoes:
            if nome.endswith(ext):
                return pasta
    return "Outros"

planos = []
for nome in os.listdir(PASTA):
    caminho = os.path.join(PASTA, nome)
    if not os.path.isfile(caminho):
        continue
    destino = descobrir_destino(nome)
    planos.append((caminho, destino))
    print(f"MOVERIA: {nome} → {destino}")

if planos and input("Confirmar? (sim/não): ") == "sim":
    for origem, destino in planos:
        os.makedirs(os.path.join(PASTA, destino), exist_ok=True)
        shutil.move(origem, os.path.join(PASTA, destino))
    print(f"{len(planos)} arquivos organizados ✔")

💡 Por que ano-mês-dia?
No formato %Y-%m-%d, a ordem ALFABÉTICA das pastas é também a ordem CRONOLÓGICA — seus backups se organizam sozinhos na listagem!

EX 12

Projeto bônus: Raio-X da pasta 🔬

⭐⭐⭐ desafio
🎯 Objetivo

Um relatório completo da pasta, gravado em CSV (olá, Semana 13!) — sem código pronto.

🧭 Roteiro
  1. Percorra o laboratório (e subpastas, se quiser ousar com os.walk — pesquise!)
  2. Para cada arquivo: nome, extensão, tamanho em KB
  3. Grave tudo em raio_x.csv com DictWriter
  4. No final, exiba: total de arquivos, tamanho total e o MAIOR arquivo (padrão maior/menor da Semana 3!)
✅ Exemplo de execução
terminal
raio_x.csv gerado: 7 arquivos, 0.14 KB no total
Maior arquivo: planilha.xlsx (0.02 KB)
🔑 Ver solução

Só abra depois de tentar!

solucao_ex12.py
import os
import csv

PASTA = "laboratorio"

linhas = []
for nome in os.listdir(PASTA):
    caminho = os.path.join(PASTA, nome)
    if os.path.isfile(caminho):
        linhas.append({
            "nome": nome,
            "extensao": nome.split(".")[-1],
            "kb": round(os.path.getsize(caminho) / 1024, 2)
        })

with open("raio_x.csv", "w", newline="", encoding="utf-8") as arquivo:
    escritor = csv.DictWriter(arquivo, fieldnames=["nome", "extensao", "kb"])
    escritor.writeheader()
    for linha in linhas:
        escritor.writerow(linha)

total_kb = 0
maior_nome = ""
maior_kb = 0
for linha in linhas:
    total_kb = total_kb + linha["kb"]
    if linha["kb"] > maior_kb:
        maior_kb = linha["kb"]
        maior_nome = linha["nome"]

print(f"raio_x.csv gerado: {len(linhas)} arquivos, {total_kb:.2f} KB no total")
print(f"Maior arquivo: {maior_nome} ({maior_kb} KB)")
