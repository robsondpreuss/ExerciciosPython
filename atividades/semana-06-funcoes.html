01

def: criando suas próprias funções

Conceito

Você já USA funções desde a Semana 1: print(), input(), len()... Agora vai CRIAR as suas. A receita:

estrutura.py
def nome_da_funcao():      # 1. DEFINE (ensina a receita)
    print("Fazendo algo...")

nome_da_funcao()           # 2. CHAMA (executa a receita)

Atenção: definir NÃO executa! A função só roda quando é chamada — e pode ser chamada quantas vezes você quiser. Essa é a mágica: escreve uma vez, usa mil vezes.

02

return: a função que devolve

Conceito

A diferença mais importante da semana: print MOSTRA um valor na tela e pronto. return ENTREGA o valor para quem chamou — e aí você pode guardar numa variável, usar numa conta, passar para outra função...

EX 04

print vs return: o duelo

⭐⭐ médio
🎯 Objetivo

Entender de uma vez por todas a diferença.

🧭 Passo a passo
  1. PREVEJA cada linha da saída (uma delas vai te surpreender!):
ex04_duelo.py
def soma_print(a, b):
    print(a + b)

def soma_return(a, b):
    return a + b

resultado = soma_print(2, 3)
print(resultado)

resultado = soma_return(2, 3)
print(resultado)
print(resultado * 10)
✅ Saída esperada
terminal
5
None
5
50
🔑 Ver solução

Só abra depois de tentar!

A surpresa é o None: soma_print mostra o 5 na tela, mas não DEVOLVE nada — e função sem return devolve None. Já soma_return entrega o valor, que pode ser guardado e reutilizado (resultado * 10). Regra prática: funções que calculam devem retornar; quem decide mostrar é quem chamou.

EX 05

Compondo funções

⭐⭐ médio
🎯 Objetivo

Usar o retorno de uma função como entrada de outra.

🧭 Passo a passo
  1. Crie dobro(n) que retorna n * 2 e quadrado(n) que retorna n ** 2
  2. PREVEJA: quanto dá dobro(quadrado(3))? E quadrado(dobro(3))?
✅ Saída esperada
terminal
18
36
🔑 Ver solução

Só abra depois de tentar!

solucao_ex05.py
def dobro(n):
    return n * 2

def quadrado(n):
    return n ** 2

print(dobro(quadrado(3)))    # quadrado(3)=9 → dobro(9)=18
print(quadrado(dobro(3)))    # dobro(3)=6 → quadrado(6)=36

O Python resolve de DENTRO para FORA. Compor funções assim só é possível porque elas RETORNAM — com print, nada disso funcionaria.

EX 06

Funções que respondem sim ou não

⭐⭐ médio
🎯 Objetivo

Retornar True/False para usar direto em condições.

🧭 Passo a passo
  1. Crie eh_par(n) que retorna True se n for par
  2. Use-a num if: if eh_par(numero):
  3. Dica de elegância: a comparação JÁ é True/False — retorne ela direto!
✅ Exemplo de execução
terminal
Digite um número: 8
8 é par!
🔑 Ver solução

Só abra depois de tentar!

solucao_ex06.py
def eh_par(n):
    return n % 2 == 0     # a comparação já devolve True/False!

numero = int(input("Digite um número: "))

if eh_par(numero):
    print(f"{numero} é par!")
else:
    print(f"{numero} é ímpar!")

Nada de if n % 2 == 0: return True else: return False — funciona, mas é dar uma volta enorme no quarteirão. 😄

Uma função, várias turmas

⭐⭐ médio

Sentir o poder do reuso.

🔑 Ver solução

solucao_ex09.py
def calcular_media(notas):
    return sum(notas) / len(notas)

Sem função, você copiaria a conta duas vezes. Com função, a lógica mora num lugar só — se precisar mudar, muda UMA vez.

04

Escopo: onde as variáveis moram

Conceito

Variável criada DENTRO de uma função é local: nasce quando a função roda e morre quando ela termina. Do lado de fora, ela simplesmente não existe!

EX 11

Local vence global?

⭐⭐⭐ desafio
🎯 Objetivo

Ver o que acontece quando dentro e fora têm o mesmo nome.

🧭 Passo a passo
  1. PREVEJA com cuidado, depois execute:
ex11_global.py
mensagem = "Eu sou a global"

def testar():
    mensagem = "Eu sou a local"
    print(mensagem)

testar()
print(mensagem)
✅ Saída esperada
terminal
Eu sou a local
Eu sou a global
🔑 Ver solução

Só abra depois de tentar!

São DUAS variáveis diferentes que por coincidência têm o mesmo nome! Dentro da função, a local "ganha". Fora, a global continua intacta — a função nem encostou nela. Por isso funções são seguras: o que acontece na função, fica na função. 😄

EX 13

A validação vira função

⭐⭐⭐ desafio
🎯 Objetivo

Empacotar a validação de entrada da Semana 3 para usar em qualquer programa.

🧭 Passo a passo
  1. Crie pedir_nota() que pergunta, repete enquanto for inválida e RETORNA a nota válida
  2. Use-a duas vezes para calcular a média de 2 provas
✅ Exemplo de execução
terminal
Nota (0 a 10): 15
Inválida!
Nota (0 a 10): 8
Nota (0 a 10): 6
Média: 7.0
🔑 Ver solução

Só abra depois de tentar!

solucao_ex13.py
def pedir_nota():
    nota = float(input("Nota (0 a 10): "))
    while nota < 0 or nota > 10:
        print("Inválida!")
        nota = float(input("Nota (0 a 10): "))
    return nota

nota1 = pedir_nota()
nota2 = pedir_nota()
print(f"Média: {(nota1 + nota2) / 2:.1f}")

Repare na elegância: quem usa pedir_nota() tem a GARANTIA de receber uma nota válida — toda a chatice da validação ficou escondida dentro da função.

EX 14

A calculadora refatorada

⭐⭐⭐ desafio
🎯 Objetivo

Reescrever o projeto da Semana 2 com uma função que calcula e retorna.

🧭 Passo a passo
  1. Crie calcular(n1, operacao, n2) que RETORNA o resultado (ou None para operação inválida)
  2. O programa principal só pede os dados, chama a função e mostra
✅ Exemplo de execução
terminal
Primeiro número: 8
Operação: *
Segundo número: 7
Resultado: 56.0
🔑 Ver solução

Só abra depois de tentar!

solucao_ex14.py
def calcular(n1, operacao, n2):
    if operacao == "+":
        return n1 + n2
    elif operacao == "-":
        return n1 - n2
    elif operacao == "*":
        return n1 * n2
    elif operacao == "/":
        if n2 == 0:
            return None
        return n1 / n2
    return None

n1 = float(input("Primeiro número: "))
op = input("Operação: ")
n2 = float(input("Segundo número: "))

resultado = calcular(n1, op, n2)
if resultado is None:
    print("Operação inválida!")
else:
    print(f"Resultado: {resultado}")

EX 15

Projeto: Tua Caneca v4 — agora com funções ☕

⭐⭐⭐ desafio
🎯 Objetivo

Refatorar o orçamento das Semanas 2 e 4 em três funções com responsabilidades claras.

🧭 Requisitos
  1. Crie calcular_subtotal(quantidade) → retorna quantidade × R$ 25,00
  2. Crie definir_desconto(quantidade) → retorna 0.15, 0.10 ou 0
  3. Crie exibir_resumo(quantidade) → usa as duas anteriores e imprime o orçamento
  4. O programa principal vira DUAS linhas!
✅ Exemplo de execução
terminal
Quantidade de canecas: 12
Subtotal: R$ 300.00
Desconto: 10%
TOTAL: R$ 270.00
🔑 Ver solução

Só abra depois de tentar!

solucao_ex15.py
PRECO = 25.00

def calcular_subtotal(quantidade):
    return quantidade * PRECO

def definir_desconto(quantidade):
    if quantidade >= 20:
        return 0.15
    elif quantidade >= 10:
        return 0.10
    return 0

def exibir_resumo(quantidade):
    subtotal = calcular_subtotal(quantidade)
    desconto = definir_desconto(quantidade)
    total = subtotal * (1 - desconto)
    print(f"Subtotal: R$ {subtotal:.2f}")
    print(f"Desconto: {desconto * 100:.0f}%")
    print(f"TOTAL: R$ {total:.2f}")

qtd = int(input("Quantidade de canecas: "))
exibir_resumo(qtd)
EX 16

Projeto: Jogo de adivinhação refatorado 🎲

⭐⭐⭐ desafio
🎯 Objetivo

Reorganizar o jogo da Semana 3 em funções.

🧭 Requisitos
  1. Função sortear() → retorna random.randint(1, 50)
  2. Função dar_dica(palpite, segredo) → imprime "alto"/"baixo"
  3. Função jogar() → contém o loop e retorna o número de tentativas
  4. Programa principal: chama jogar() e parabeniza
✅ Exemplo de execução
terminal
Adivinhe o número entre 1 e 50!
Seu palpite: 25
Muito baixo! ⬆
Seu palpite: 38
🎉 Acertou em 2 tentativas!
🔑 Ver solução

Só abra depois de tentar!

solucao_ex16.py
import random

def sortear():
    return random.randint(1, 50)

def dar_dica(palpite, segredo):
    if palpite > segredo:
        print("Muito alto! ⬇")
    elif palpite < segredo:
        print("Muito baixo! ⬆")

def jogar():
    segredo = sortear()
    tentativas = 0
    palpite = 0
    print("Adivinhe o número entre 1 e 50!")
    while palpite != segredo:
        palpite = int(input("Seu palpite: "))
        tentativas += 1
        dar_dica(palpite, segredo)
    return tentativas

total = jogar()
print(f"🎉 Acertou em {total} tentativas!")
EX 17

Projeto bônus: Caixa de ferramentas 🧰

⭐⭐⭐ desafio
🎯 Objetivo

Montar sua biblioteca pessoal de funções (sem código pronto!).

🧭 Roteiro
  1. Crie um arquivo ferramentas.py com pelo menos 4 funções suas: eh_par(n), calcular_media(lista), pedir_nota(), tabuada(n)...
  2. Monte um menu em loop que permite testar cada ferramenta
  3. Capriche nos nomes: uma boa função se explica pelo nome!
✅ Exemplo de execução
terminal
=== CAIXA DE FERRAMENTAS ===
1-Par ou ímpar  2-Média  3-Tabuada  4-Sair
Opção: 1
Número: 14
14 é par!
💡 Você percebeu?
Com funções, adicionar uma opção nova ao menu é só escrever a função e mais um elif. Programas organizados assim crescem sem virar espaguete! 🍝
🔑 Ver solução

Só abra depois de tentar!

solucao_ex17.py
def eh_par(n):
    return n % 2 == 0

def calcular_media(notas):
    return sum(notas) / len(notas)

def tabuada(n):
    for i in range(1, 11):
        print(f"{n} x {i} = {n * i}")

while True:
    print()
    print("=== CAIXA DE FERRAMENTAS ===")
    print("1-Par ou ímpar  2-Média  3-Tabuada  4-Sair")
    opcao = int(input("Opção: "))

    if opcao == 1:
        n = int(input("Número: "))
        if eh_par(n):
            print(f"{n} é par!")
        else:
            print(f"{n} é ímpar!")
    elif opcao == 2:
        notas = []
        for i in range(1, 4):
            notas.append(float(input(f"Nota {i}: ")))
        print(f"Média: {calcular_media(notas):.1f}")
    elif opcao == 3:
        tabuada(int(input("Qual tabuada? ")))
    elif opcao == 4:
        break
    else:
        print("Opção inválida!")
