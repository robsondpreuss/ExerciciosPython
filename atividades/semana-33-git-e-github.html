01

O primeiro gráfico

Conceito

Instale com pip install matplotlib. A convenção é importar o submódulo pyplot como plt: import matplotlib.pyplot as plt. O fluxo básico: montar o gráfico → plt.show() abre a janela (feche-a para o programa continuar).

EX 01

Barras no ar 📊

⭐⭐ médio
🎯 Objetivo

Seu primeiro gráfico em 4 linhas.

🧭 Passo a passo
  1. Digite e execute — uma JANELA vai abrir com o gráfico:

import matplotlib.pyplot as plt

produtos = ["branca", "preta", "azulejo"]
totais = [175.0, 407.5, 120.0]

plt.bar(produtos, totais)
plt.show()

A pizza 🍕

🎯 Objetivo

Participação de cada produto no faturamento.

03

Salvando em PNG

Conceito

Gráfico bom é gráfico que viaja: plt.savefig("nome.png", dpi=150) grava a imagem. ⚠️ A pegadinha clássica: salve ANTES do show — o show "consome" a figura, e salvar depois gera um PNG em branco!

05

O gráfico certo para cada pergunta

Conceito

A regra de ouro da visualização:

PerguntaGráfico
Comparar categorias ("quem vende mais?")Barras
Evolução no tempo ("estamos crescendo?")Linha
Partes de um todo ("quanto % cada um?")Pizza (≤ 5 fatias)

Gráfico errado conta a história errada — e quem escolhe é você, não a ferramenta.

EX 09

Projeto: Painel Tua Caneca em PNG 🖼️

⭐⭐⭐ desafio
🎯 Objetivo

Os 3 gráficos oficiais do negócio, salvos e prontos para o relatório.

🧭 Requisitos
  1. A partir do vendas.csv: (1) barras do faturamento por produto, (2) pizza da participação, (3) linha do faturamento por dia
  2. Cada um com título, cores e tight_layout, salvo em PNG (dpi=150)
  3. Entre um gráfico e outro: plt.figure() inicia uma figura nova (senão eles se misturam!)
✅ Exemplo de execução
terminal
por_produto.png ✔
participacao.png ✔
por_dia.png ✔
🔑 Ver solução

Só abra depois de tentar!

solucao_ex09.py
import pandas as pd
import matplotlib.pyplot as plt

df = pd.read_csv("vendas.csv")

# 1. Barras
plt.figure(figsize=(6, 4))
df.groupby("produto")["total"].sum().plot(kind="bar", color="#3776AB")
plt.title("Faturamento por produto")
plt.ylabel("R$")
plt.tight_layout()
plt.savefig("por_produto.png", dpi=150)
print("por_produto.png ✔")

# 2. Pizza
plt.figure(figsize=(5, 5))
df.groupby("produto")["total"].sum().plot(kind="pie", autopct="%1.0f%%")
plt.title("Participação no faturamento")
plt.ylabel("")
plt.tight_layout()
plt.savefig("participacao.png", dpi=150)
print("participacao.png ✔")

# 3. Linha
plt.figure(figsize=(6, 4))
df.groupby("data")["total"].sum().plot(kind="line", marker="o", color="#FFB000")
plt.title("Faturamento por dia")
plt.ylabel("R$")
plt.tight_layout()
plt.savefig("por_dia.png", dpi=150)
print("por_dia.png ✔")

Projeto: Notas da turma com linha da média 🎓

⭐⭐⭐ desafio

Visualizar desempenho com uma linha de referência.

🧭 Passo a passo
  1. Barras com a média de cada aluno (groupby da Semana 17)
  2. Linha horizontal da nota de corte: plt.axhline(7, color="red", linestyle="--")

✅ Saída esperada
terminal
(barras dos alunos com a linha vermelha do 7)
🔑 Ver solução

Só abra depois de tentar!

solucao_ex10.py
import pandas as pd
import matplotlib.pyplot as plt

notas = pd.DataFrame({
    "aluno": ["Ana", "Ana", "Bruno", "Bruno", "Carla", "Carla"],
    "nota": [8.0, 8.5, 6.0, 5.0, 9.5, 9.5]
})

medias = notas.groupby("aluno")["nota"].mean()

medias.plot(kind="bar", color="#3776AB")
plt.axhline(7, color="red", linestyle="--", label="Nota de corte")
plt.title("Média por aluno")
plt.ylabel("Nota")
plt.legend()
plt.tight_layout()
plt.savefig("medias_turma.png", dpi=150)
plt.show()
