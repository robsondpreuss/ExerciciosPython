01

Lógica de Programação: pensando antes de programar

Conceito

Um algoritmo é uma sequência de passos ordenados para resolver um problema. Antes de escrever código, todo programador pensa nos passos.

Exemplo do mundo real — algoritmo para fazer café: pegar a garrafa térmica → ferver a água → colocar o pó no filtro → despejar a água quente → esperar coar → servir.

Repare: a ordem importa! Se você despejar a água antes de colocar o pó, o resultado será errado. Programação é exatamente isso: dar instruções claras, completas e na ordem certa.

03

Variáveis: a memória do programa

Conceito

Uma variável é como uma caixinha com etiqueta onde guardamos um valor para usar depois.

exemplo.py
nome = "Maria"      # caixinha "nome" guarda o texto Maria
idade = 25          # caixinha "idade" guarda o número 25
altura = 1.68       # caixinha "altura" guarda o decimal 1.68

Regras para nomes de variáveis:

  • ✅ Pode: letras, números e underline (_) → nome_completo, idade2
  • ❌ Não pode: começar com número → 2nome (erro!)
  • ❌ Não pode: espaços → nome completo (erro!)
  • ⚠️ Acentos: tecnicamente funcionam, mas evite! Use salario em vez de salário

EX 11

A troca de valores (clássico!)

⭐⭐ médio
🎯 Objetivo

Resolver um dos problemas mais clássicos da lógica de programação.

Contexto: você tem duas variáveis e precisa trocar os valores entre elas:

ex11_troca.py
a = "café"
b = "leite"
# Objetivo: no final, a deve valer "leite" e b deve valer "café"
🧭 Passo a passo
  1. Primeiro tente o jeito ingênuo e veja por que NÃO funciona:
    tentativa_errada.py
    a = b   # a agora vale "leite"... mas o "café" foi perdido!
b = a   # b recebe "leite" de novo. Deu errado!
  2. Pense na vida real: para trocar o conteúdo de dois copos, você precisa de um terceiro copo auxiliar
  3. Use uma variável auxiliar e complete:
    ex11_troca.py
    auxiliar = a    # guarda o "café" em segurança
a = ____        # complete
b = ____        # complete
  4. Confira com print(a) e print(b)
✅ Saída esperada
terminal
leite
café
🚀 Desafio extra
Python tem um atalho elegante que dispensa a variável auxiliar: a, b = b, a. Teste e comprove!
🔑 Ver solução

Só abra depois de tentar!

solucao_ex11.py
a = "café"
b = "leite"

auxiliar = a    # guarda "café" em segurança
a = b           # a recebe "leite"
b = auxiliar    # b recebe o "café" que estava guardado

print(a)   # leite
print(b)   # café

# Desafio extra — o jeito "pythônico":
a, b = b, a    # troca os dois de uma vez só!
