01

O laço while

Conceito

O while repete um bloco de código enquanto a condição for True. A estrutura clássica usa um contador:

estrutura.py
contador = 1            # 1. inicializa
while contador <= 5:    # 2. condição de parada
    print(contador)
    contador = contador + 1   # 3. atualiza (ESSENCIAL!)

⚠️ Se você esquecer o passo 3, a condição nunca vira False e o programa repete para sempre — o famoso loop infinito (você vai criar um de propósito no Exercício 3!).

O laço for e o range()

Conceito

O for repete um número conhecido de vezes, sem precisar criar e atualizar contador na mão. Ele anda pelos valores gerados por range():

FormaGera
range(5)0, 1, 2, 3, 4
range(1, 6)1, 2, 3, 4, 5
range(0, 11, 2)0, 2, 4, 6, 8, 10
range(10, 0, -1)10, 9, 8, ... 1

⚠️ O número final NUNCA entra! range(1, 6) para no 5. É a pegadinha número 1 do for.

EX 09

Fatorial

⭐⭐⭐ desafio
🎯 Objetivo

Usar um acumulador MULTIPLICATIVO.

Conceito: o fatorial de 5 (escrito 5!) é 5 × 4 × 3 × 2 × 1 = 120.

🧭 Passo a passo
  1. Peça um número n
  2. Crie resultado = 1 (por que 1 e não 0? Pense!)
  3. Multiplique resultado por cada i de 1 até n
  4. Exiba o fatorial
✅ Exemplo de execução
terminal
Calcular o fatorial de: 5
5! = 120
💡 Por que começar com 1?
Se o acumulador de multiplicação começasse em 0, tudo multiplicado por 0 daria... 0! Para somar, começamos do 0; para multiplicar, do 1 (os "elementos neutros" de cada operação).
🔑 Ver solução

Só abra depois de tentar!

solucao_ex09.py
n = int(input("Calcular o fatorial de: "))

resultado = 1
for i in range(1, n + 1):
    resultado = resultado * i

print(f"{n}! = {resultado}")

EX 12

Maior e menor

⭐⭐⭐ desafio
🎯 Objetivo

Encontrar extremos com atualização condicional (sem usar max/min).

🧭 Passo a passo
  1. Leia o PRIMEIRO número fora do loop e use-o para inicializar maior e menor
  2. Leia os outros 4 números num for
  3. Para cada um: se for maior que o maior atual, atualize; se for menor que o menor, atualize
  4. Exiba os dois no final
✅ Exemplo de execução
terminal
Digite 5 números:
Número 1: 7
Número 2: 3
Número 3: 12
Número 4: 5
Número 5: 9
Maior: 12.0
Menor: 3.0
💡 Por que inicializar com o primeiro número?
Se você começar com maior = 0 e o usuário só digitar números negativos, o resultado sai errado! Inicializar com o primeiro valor real é a forma segura.
🚀 Desafio extra
Confira seu resultado usando as funções prontas max() e min() (você vai precisar de listas — spoiler da Semana 4!).
🔑 Ver solução

Só abra depois de tentar!

solucao_ex12.py
print("Digite 5 números:")

maior = float(input("Número 1: "))
menor = maior

for i in range(2, 6):
    numero = float(input(f"Número {i}: "))
    if numero > maior:
        maior = numero
    if numero < menor:
        menor = numero

print(f"Maior: {maior}")
print(f"Menor: {menor}")

break e continue

Conceito

Dois comandos para controlar o loop por dentro: break encerra o loop na hora; continue pula para a próxima volta, ignorando o resto do bloco.

  1. Crie soma = 0 e um loop while True: (proposital — quem vai parar é o break!)

FizzBuzz — o clássico das entrevistas! 🏆

⭐⭐⭐ desafio
🎯 Objetivo

Resolver o exercício mais famoso de lógica de programação (cai em entrevista de emprego de verdade!).

Regras: para os números de 1 a 30 — múltiplo de 3: imprima "Fizz" · múltiplo de 5: "Buzz" · múltiplo dos DOIS: "FizzBuzz" · senão: o próprio número.

🧭 Passo a passo
  1. Percorra de 1 a 30
  2. ATENÇÃO à ordem dos testes: qual condição precisa vir primeiro?
  3. Teste especialmente os números 15 e 30
✅ Saída esperada (início)

💡 A pegadinha
Se você testar "múltiplo de 3" primeiro, o 15 vai cair nesse caso e imprimir só "Fizz". A condição MAIS ESPECÍFICA (múltiplo de 3 E de 5) precisa vir primeiro!
🔑 Ver solução

Só abra depois de tentar!

solucao_ex19.py

    if i % 3 == 0 and i % 5 == 0:
        print("FizzBuzz")
    elif i % 3 == 0:
        print("Fizz")
    elif i % 5 == 0:
        print("Buzz")
    else:
        print(i)

EX 20

Projeto: Jogo de adivinhação 🎲

⭐⭐⭐ desafio
🎯 Objetivo

Construir um jogo de verdade com while, if/elif e números aleatórios.

Novidade: a linha import random (no topo do arquivo) traz funções de sorteio. random.randint(1, 50) sorteia um inteiro entre 1 e 50.

🧭 Requisitos
  1. Sorteie o número secreto
  2. Enquanto o palpite for diferente do segredo: peça um palpite, conte a tentativa e dê a dica "Muito alto!" ou "Muito baixo!"
  3. Ao acertar, parabenize mostrando o número de tentativas
✅ Exemplo de execução
terminal
Adivinhe o número entre 1 e 50!
Seu palpite: 25
Muito baixo! ⬆
Seu palpite: 38
Muito alto! ⬇
Seu palpite: 31
🎉 Acertou em 3 tentativas!
🚀 Desafio extra
Limite a 7 tentativas: se estourar, encerre com break e revele o número. (Será que 7 sempre basta para 1-50? Pesquise "busca binária" 😉)
🔑 Ver solução

Só abra depois de tentar!

solucao_ex20.py
import random

segredo = random.randint(1, 50)
tentativas = 0
palpite = 0

print("Adivinhe o número entre 1 e 50!")

while palpite != segredo:
    palpite = int(input("Seu palpite: "))
    tentativas = tentativas + 1
    if palpite > segredo:
        print("Muito alto! ⬇")
    elif palpite < segredo:
        print("Muito baixo! ⬆")

print(f"🎉 Acertou em {tentativas} tentativas!")

Projeto: Caixa registradora Tua Caneca 💰

⭐⭐⭐ desafio
🎯 Objetivo

Somar uma venda inteira com loop sentinela, acumulador e contador.

🧭 Requisitos
  1. Leia o valor de cada item vendido até o usuário digitar 0
  2. Acumule o total e conte os itens
  3. No fechamento, exiba: quantidade de itens, total e valor médio por item
✅ Exemplo de execução
terminal
=== CAIXA TUA CANECA ===
Digite o valor de cada item (0 para fechar a conta)
Valor do item: R$ 25
Valor do item: R$ 25
Valor do item: R$ 40
Valor do item: R$ 0
Itens vendidos: 3
TOTAL: R$ 90.00
Valor médio: R$ 30.00
💡 Cuidado com a divisão!
Se o usuário digitar 0 logo de cara, total / itens seria uma divisão por zero. Proteja com if itens > 0.
🔑 Ver solução

Só abra depois de tentar!

solucao_ex21.py
print("=== CAIXA TUA CANECA ===")
print("Digite o valor de cada item (0 para fechar a conta)")

total = 0
itens = 0

while True:
    valor = float(input("Valor do item: R$ "))
    if valor == 0:
        break
    total = total + valor
    itens = itens + 1

print(f"Itens vendidos: {itens}")
print(f"TOTAL: R$ {total:.2f}")

if itens > 0:
    media = total / itens
    print(f"Valor médio: R$ {media:.2f}")

Projeto bônus: todas as tabuadas (loop aninhado)

⭐⭐⭐ desafio
🎯 Objetivo

Descobrir sozinho o loop dentro de loop (sem código pronto!).

🧭 Roteiro
  1. Você já fez a tabuada de UM número (Exercício 8)
  2. Agora coloque aquele for DENTRO de outro for que percorre os números de 1 a 10
  3. Imprima um título antes de cada tabuada e uma linha em branco depois
✅ Saída esperada (início)
terminal
--- Tabuada do 1 ---
1 x 1 = 1
1 x 2 = 2
(...)
--- Tabuada do 2 ---
2 x 1 = 2
2 x 2 = 4
(...)
💡 Como pensar
O loop de fora escolhe QUAL tabuada (n = 1, 2, 3...). Para cada n, o loop de dentro roda as 10 multiplicações. Total: 100 prints com 4 linhas de código!
🔑 Ver solução

Só abra depois de tentar!

solucao_ex22.py
for n in range(1, 11):
    print(f"--- Tabuada do {n} ---")
    for i in range(1, 11):
        print(f"{n} x {i} = {n * i}")
    print()
